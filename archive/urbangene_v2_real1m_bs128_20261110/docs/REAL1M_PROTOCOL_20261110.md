# UrbanGene V2：百万真实街景、大 batch 实验

配置日期：2026-11-10（北京时间）。本轮遵循用户要求，停止 20k 旧实验，单独启动新模型。

## 目标与模型

检验扩大真实数据覆盖面和有效 batch 后，分组发现是否改善。
使用冻结的本地 DINOv3 ViT-L/16，输入 448×448 RGB，提取 1024×28×28 特征。
特征进入 Adaptive Spatial Slot Encoder（最多 32 个 Slot，128 维，3 次竞争迭代），
由共享空间 MLP 解码器重建特征。沿用 feature MSE；本轮不改变发现模型结构，
不训练 RGB 生成器，不使用类别、实例掩码、检测框或对象数量标签。

## 数据

- 目标：1,000,000 张训练照片、4,096 张验证照片；完整核验后才允许正式训练。
- 训练来自 500,000 个街景全景，每个取两个相反朝向；在 296 座符合条件的城市中近似均衡采样。
- 使用 NAS 中现有 Google 街景照片与通用图像质量筛选清单，不生成合成图片。
- 固定种子 42；每张图片做 SHA256、RGB 完整解码检查；全数据排除完全相同的文件内容。
- 训练、验证按城市及全景 ID 隔离，训练全景不能出现在验证中。
- 原 20k 实验的 512 张验证照片保留在新验证集前缀；新增验证全景排除旧训练全景。
- Adelaide 整城保留为后续测试，不参与本轮训练或验证。未设置地理距离缓冲，
  因此不主张排除了相邻拍摄点或视觉近重复。
- 通用质量筛选清单不提供对象语义标签。完成标志为数据目录中的 `READY.json`；
  `preparation.json` 中的实时数量是已核验数量，不能将目标数当作完成数量。

## GPU、存储及恢复

模型计算只使用 GPU；无卡则排队，最多两张 GPU，总数包含特征提取和训练。
仅选择无计算进程、显存低于 1 GiB、利用率低于 10% 的卡，并持有共享 GPU 租约。
RGB 解码、哈希、文件读取及单元测试使用 CPU；没有 CPU 模型计算回退。

每 2,048 张图片提交一个独立特征分片，float16 总量约 1.46 TiB；
不再合并为第二份完整巨型数组。启动要求 NAS 至少剩余 2 TiB。
所有结果、临时文件、日志和新检查点写入 NAS 的新目录。
RGB 核验基于 SQLite 恢复；特征提取按已完成分片恢复，部分分片另存后重做。
进入训练前检查图片 ID 对齐、分片 SHA256、DINO 权重身份及完整数量。
训练续跑检查配置、特征索引身份、GPU 数量，恢复优化器、随机状态和采样位置。
训练读取使用 4 个线程，避免容器 64 MiB 的 `/dev/shm` 限制。

## 训练参数

| 项目 | 设置 |
|---|---|
| 初始化 | 从头训练；GPU smoke 权重丢弃，不加载旧模型 |
| 有效全局 batch | 128（旧实验为 4） |
| 每张 GPU 的 micro batch | 16 |
| 两张 GPU | 每轮前后向共 32 张，梯度累积 4 次再更新 |
| 一张 GPU | 每轮前后向 16 张，梯度累积 8 次再更新 |
| 更新预算 | 100,000 次，即 12,800,000 次图片呈现，约 12.8 遍数据 |
| 优化器 | AdamW；FP32；梯度裁剪 1.0 |
| 学习率 | 3e-4；前 2,000 次更新 warmup，之后 cosine 降至 3e-5 |
| 验证及续训检查点 | 每 1,000 次更新及最后一次更新 |
| 固定照片预览及里程碑检查点 | 首次验证；之后每 5,000 次更新输出预览，每 5,000 次保存里程碑 |

正式计算前，GPU smoke 使用真实旧缓存完成 3 次 batch-128 更新，检查损失、梯度有限性和显存。
梯度累积按每个 micro batch 的样本比例加权。batch 128 指有效更新 batch，
不意味着每张卡一次放入 128 张。特征提取的 batch 与模型训练独立。

## 评估边界

记录全部 4,096 张验证图的特征重建 MSE，以及公共前 512 张的 MSE。
每张验证图使用固定随机种子，监控注意力最大占比、解码权重熵和固定原图上的分组预览。
保存软注意力和解码权重，避免只看彩色 argmax 分区。
没有独立真实实例标注，不能报告真实实例准确率，也不能仅凭 loss 下降认定逐棵树分离成功。
本轮同时改变数据量、城市覆盖、batch 和学习率计划，属于扩大实验，不能单独归因于某一因素。
旧实验在第 27 轮进行中、step 133,500 按用户要求停止；已保存检查点及结果完整保留。
