## 2. 原文实际做了什么

MUSC 是 Multiscale U-Net-like Sparse Coding。关键是把 U-Net 的解码分支改造成线性字典：保留卷积、转置卷积、不同分辨率编码的融合和共享合成路径；去掉合成字典中的激活、归一化及偏置。所有尺度一起构成一个多尺度编码集合。

原文公式 (7)–(13) 使用多尺度线性字典合成输出，并展开有限次 ISTA/LISTA 推断非负编码。实际框架允许编码残差字典、预条件分析字典和输出合成字典分别学习，阈值按迭代、尺度和通道学习。论文实验采用 5 次展开。

论文主要证据来自去雨、CT、MRI 和超分辨率。论文的任务驱动训练使用输入与目标成对的数据；它没有验证无语义标注街景的共享基因发现、对象发现或跨图像语义组合。把输入和目标设为同一张街景，是本项目拟采用的自监督适配。

重要边界：论文附录 D 及官方实现允许对输出施加非负截断。线性字典本身具有加性，但截断后的显示图不再严格具有加性。原文附录 B 关于学习阈值不会退化的论证面向其逆问题，不能直接保证街景恒等重建任务不会学成近似复制。

## 3. 与当前代码的差别

核对源文件：`/host/mnt/nas/urban-visual-gene/additive_gene_1m_20261115_4gpu_bs1024/source/model.py`。

当前主模型对 256×256 RGB 图像编码，在 16×16 网格预测 256 个通道，每位置 ReLU 后取 Top-4。共享字典为 256×64，每个基因是一个 64 维向量；加权求和形成 64×16×16 特征，再经带 GroupNorm、SiLU 和 Sigmoid 的非线性解码器生成 RGB。

因此当前严格加性只发生在潜在特征层。它既不是多尺度稀疏编码，也不保证单独解码的基因图像能够逐像素相加还原整体。当前编码器具有多层感受野，但最终基因编码只有一个分辨率；这与多尺度基因编码不同。

上次已核验的验证结果中，稀疏模型 PSNR 约 23.92 dB，普通 AE 约 29.51 dB；稀疏模型在该验证集实际激活 76/256 个基因。这支持优先研究稀疏瓶颈及利用率，不足以证明单一尺度就是唯一原因。Top-4 过强、竞争造成基因闲置和字典表达能力都需要消融。

## 4. 推荐主候选：多尺度稀疏编码 + 线性 RGB 合成

让图像的编码为多个尺度的非负激活图：

\[
A(I)=\{A_s(I)\}_{s=1}^{S},\qquad A_s\in\mathbb R_{\ge0}^{N_s\times H_s\times W_s}.
\]

让每个尺度经由线性共享合成路径到达 RGB：

\[
\widehat I=\mathcal D_\theta(A)=\sum_{s=1}^{S}D_{\theta,s}A_s
=\sum_{s,j}D_{\theta,s,j}A_{s,j}.
\]

这里 D_s 表示从该尺度编码到最终 RGB 的完整线性算子，不是把任意非线性 U-Net 称为字典。卷积权重可正可负，激活系数可保持非负。所有输入图像共用同一套字典参数。

第一版可从 16×16、32×32、64×64 三个编码尺度开始，必要时才增加 128×128 分支。此为计算预算和避免复制的工程起点，不是论文的原始五尺度配置。原文的五尺度配置应保留为可选复现参考。

编码可以非线性。初版可采用论文式 5 步 LISTA：

\[
A^{t+1}=\operatorname{ReLU}\left[A^t+\eta_t B^\top(I-CA^t)-\tau_t\right],\qquad \widehat I=DA^T.
\]

A 是多尺度激活的集合，C 是计算残差的编码字典，B^T 是可学习分析算子，D 是输出字典。阈值和步长可按尺度、通道、迭代学习。B 与 C 解耦时应称为学习展开，不能直接宣称精确求解固定 Lasso 或具有经典 ISTA 的全部收敛保证。

对本项目的严格加性版本，RGB 合成路径不能包含 GroupNorm、BatchNorm、SiLU、ReLU、Sigmoid 或数据依赖门控；卷积偏置应去掉。可保留线性跨尺度连接，但所有进入合成器的输入都必须经过被记录的基因编码，不能增加未计入的图像旁路。

## 5. 加性能够保证什么

固定线性字典后：

\[
\mathcal D(A+B)=\mathcal D(A)+\mathcal D(B).
\]

这保证未截断模型输出的贡献可以准确求和、删除或替换；不保证编码器满足 E(I+J)=E(I)+E(J)，也不保证两张完整街景的编码求和会形成透视、遮挡合理的新街景。直接整图编码相加可能产生叠影，需要额外的布局、对齐或生成先验研究。

多尺度卷积基因不等同于树、建筑等实例，也不是每图仅使用 N 个标量。N_s 个通道表示该尺度的共享模板类型；每个类型有一张空间激活图。移动一个激活相当于在对应位置使用模板；必须同时报告模板数量、空间系数总数、非零系数数目和数值精度。

如果研究要求每张图只有 n 个全局标量，MUSC 不能直接满足，需要另行约束位置与空间图的参数化。

如果保留非线性 RGB 解码器，可以作为追求视觉质量的对照，但严格加性仍只发生在进入该解码器之前的特征层。两种定义应分别报告。

## 6. 建议实验顺序

先用独立的 10,000 张真实街景训练集，固定空间分离的验证和测试划分；不复用曾看过的测试结果选模型。保持分辨率 256×256，固定训练样本曝光次数，并记录实际时间和显存。暂不直接重跑百万张。

第一阶段做可归因的 2×2 核心消融，所有组都用线性 RGB 合成：

| 编码 / 字典 | 单尺度卷积字典 | 多尺度卷积字典 |
| --- | --- | --- |
| 前馈编码 + 稀疏阈值 | S-FF | M-FF |
| 5 步学习展开 + 稀疏阈值 | S-LISTA | M-LISTA |

额外把当前 Top-4 + 非线性解码结构和普通 AE 在相同的 10,000 张训练集上重训作对照。已训练的百万图像模型只能作为展示参考，不能与 10,000 张新实验直接作公平排名。这样可分辨多尺度和迭代推断的贡献；不能把从现有模型到 MUSC 的全部变化都归因于多尺度。

各组不能只匹配“256 个通道”。应报告参数量、MACs、编码维数、平均每图非零系数、系数幅值和推断步数；在数个共同可达到的非零系数预算上绘制质量曲线，尽量匹配参数预算，同时单列未匹配的计算成本。当前模型理论上每图最多 16×16×4=1024 个正激活系数，实际可能更少；多尺度版本若使用更多非零系数，提升不能全部记作架构收益。

初期采用相同重建损失公平比较；现有 L1 + 0.1 LPIPS 可作为控制设置，0.1 不是论文结论。按统一激活预算调节稀疏约束。若另加显式 L1 激活正则，应控制字典/算子的尺度，避免字典变大、系数变小而绕过惩罚。学习阈值不等于已保证固定稀疏度。MSE 和 LPIPS 权重的改变留到单独消融。

第二阶段仅对验证集上的候选配置做多个随机种子复验，再扩大到 20 万或 100 万张。不要强迫所有尺度或基因均匀使用；记录长期闲置基因，按预先规定的判据研究复活机制，并单独消融。

## 7. 必须输出的结果

1. **重建质量**：固定街景原图与重建图，PSNR、SSIM、LPIPS，报告均值与分布。
2. **预算与基因利用率**：每尺度的非零系数数目、非零比例、基因使用频率、长期闲置比例及贡献能量；不要把高分辨率尺度更多的空间位置误当作更高的每位置使用率。
3. **原子与贡献可视化**：用单位脉冲编码提取 Dδ；分别展示原子本身、该基因在真实图像中的激活图，以及 D(A_gene) 的带符号 RGB 贡献。带符号贡献使用统一零点和色标；自然照片式的截断预览只能辅助观察。
4. **加性回放**：所有基因贡献之和与完整未截断重建的相对误差，应接近相应精度的数值误差；它是结构正确性的检查，不是新街景组合成功的科学证据。
5. **删除与交换**：删除某尺度/基因，核对差值是否等于其贡献；交换相近视角和布局图像的部分编码，评估空间变化和其余区域是否保留。线性结构保证输出差值可计算，但语义和自然度要另做评估。
6. **范围与生成限制**：报告未截断输出超出 RGB 有效范围的比例；显示时 clamp 不能改变用于加性核对的原始张量。重建 AE 本身未学习 p(A)，不能据此声称具备无条件新图像生成能力。

## 8. 判断

这篇论文非常适合作为 UrbanGene 下一版架构候选，因为它同时提供多尺度可复用字典和可核对的线性贡献分解。合理预期是改善当前单尺度稀疏瓶颈的表达；是否提高真实街景质量、是否形成可迁移的组合变量，仍须由上述实验回答。

潜在研究问题：真实街景能否由跨尺度、可复用、稀疏激活的共享视觉基因，通过加法重建，并在受控编码编辑中产生可预测的图像变化？
