# Urban Visual Gene：生成质量优先的实验协议

日期：2026-10-19。状态：研究设计；本文件不代表已训练或获得新的生成结果。

## 目标与范围

不要求单个 Gene 有人类可命名的语义。首要目标是在给定表示预算下，生成自然、细节充分、且与编码/操作对应的街景。复用和组合是随后验证的性质；不把正交、语义可解释、每个方向独立或少量 slots 当作先决条件。

不取消此前的逐实例编辑诉求，但将其列为独立实验支线。第一阶段空间 token 不等于物理对象；若最终仍要求一棵树一个可操纵单元，需要另外评价自动实例分组。

明确区分三项任务：

1. 条件重建：给定一幅新图片的 Gene 表示，生成与其对应的街景。
2. 编辑/组合：修改 Gene 后生成，并评价目标变化和非目标保持。
3. 全新采样：从学到的 Gene 分布采样，不输入真实源图。第三项需要训练表示先验，不能用原图编解码或随意混合系数代替。

## 推荐架构

以预训练图像编解码器和扩散/flow 生成器作为质量基线。DINOv3 继续作为结构特征分支，和图像外观分支共同形成空间条件。

```text
RGB ─→ 冻结图像编码器 ─→ 外观特征 ─┐
                                  ├→ 空间融合器 → 系数场 A → 共享 Gene Bank G
RGB ─→ 冻结 DINOv3 ─→ 结构特征 ────┘                    ↓
                                               条件特征 C = AG^T
随机噪声 ─→ 预训练扩散/flow 主干 + 可学习条件适配器 ─→ 图像解码器 ─→ 街景
```

第一版不要先把所有输入压成 16/32 个全局对象 slot。保持空间坐标，让相同 Gene 在不同位置以不同系数表达。以后再检验多尺度和对象绑定。

每个空间位置 p 的条件为：

\[c_p=\sum_{k\in\operatorname{TopS}(a_p)}a_{pk}g_k,\qquad
I_{\mathrm{gen}}=R_{\theta,\psi}(\epsilon,\{c_p,p\}).\]

G 是跨图像共享的字典；A 是每幅图不同的系数场。初始参数仅是候选，不构成有效性承诺：256 个空间位置（16×16 网格），512 个 256 维 Gene，每位置先激活 8 个，再比较 4/2 个。512px 输入时，16×16 是粗空间索引，不能将每个 token 当作一棵树或精确边界。

所有原图派生特征只能经过被评价的条件通路。无压缩密集特征或原图潜变量直接跳连是另一条基线，不能混入 Gene-only 主实验。若后续增加细节残差，单独报告其空间大小、精度和信息预算；残差可能承担主要信息。

训练中扩散主干接收由原图潜变量加噪得到的 z_t，这是标准去噪训练。主测试从纯随机噪声开始，原图只能通过 Gene 条件进入。低噪声 img2img、反演等单列为编辑工具，不用于证明 Gene 独自足够生成。

## 0. 先固定主干与图像编解码参考

候选主干：SDXL base 1.0 作为第一实现基线；算力、权重许可和训练工具满足时，比较 FLUX.1-dev。不宣称任何一个在本数据上最好或是最新。只在独立验证集上选择，固定后再比较字典。先做单步训练显存/吞吐检查，不占用其他任务资源。

先做同一批图片的 VAE 编解码和真实纹理/树枝/车辆/建筑边界检查。VAE 编解码是诊断参考，不是整个生成系统的理论质量上限。此前五张图的 VAE 对照只证明当前小样本可良好编解码，不证明 Gene 可生成。

预先比较 512px 接口调试与 768/1024px 质量验证；512px 的排名不直接外推到高分辨率。最终主比较采用同一输出分辨率。超分/细化前后的图像均保存，且各模型处理一致。

## 1. 先建立强条件生成基线

三个候选条件都不经过字典：

- D：原始 DINOv3 patch 特征，可学习投影；不再以固定 PCA64 作为唯一条件。
- V：图像编解码器的外观潜变量，经过与 D 同等预算的空间投影。
- DV：两者融合，总 token 数/通道数与预算固定，额外参数和计算量单列。

对每种条件先冻结生成主干，训练融合器/适配器；若验证质量不足，再对最佳条件加 LoRA 等有限主干适配。记录冻结和适配后的结果。按验证集质量与内容对应选定一条输入路径，后续所有字典模型复用同一主干起点。

密集条件无法生成相应清晰街景时，先解决条件接口、训练或主干适配，不进入强字典压缩。纯文本预训练主干可作为自然度参考，但不是同信息输入的公平重建基线。所有模型使用相同空文本/固定通用文本；禁止给某组独有的图像详细描述、城市标签或其他内容通路。

可选研究对照：RAE 在 DINO 等冻结表示后训练强图像解码器，并在表示空间训练生成模型。它说明 DINO 表示不是必然只能生成模糊图，但公开 DINOv2/SigLIP2 解码器不能直接当作 DINOv3 可兼容检查点。DINOv3 适配与场景迁移需要独立训练验证，不在第一轮同时更换表示与生成主干。

## 2. 加入 Gene，画出质量与表示预算的关系

核心对照：

| ID | 表示 | 目的 |
| --- | --- | --- |
| B0 | 预训练生成主干，不用图像条件 | 自然度和条件依赖参考 |
| B1 | 最佳密集条件，无字典 | 当前架构的高容量基线 |
| B2 | 固定随机字典 + 可学习稀疏系数 | 学习字典是否带来收益 |
| B3 | 可学习共享字典 + 稀疏系数 | Gene 主模型 |
| B4 | B3 + 原始残差旁路（只在必要时） | 质量改善是否来自旁路 |

先固定 N=256、K=512、d=256，比较每位置激活 S=8/4/2，选择有用的质量/预算折中。然后仅对最佳方案比较空间位置 N=64/256/1024；最后如有必要比较 K=256/512/1024。避免一次做完整笛卡尔积。

保持训练图像暴露量、主干起点、分辨率、优化配置和采样设置一致；主要匹配实际计算量或记录不同成本，不能仅以相同步数宣称公平。报告字典大小、位置数、活跃系数数目、系数存储精度、参数与训练显存。若未实际量化/熵编码，只称表示预算代理，不称真实压缩码率。

图表核心是 LPIPS/内容对应/盲评相对于预算的曲线。只保留在相同预算有收益或明显支持操作的 Gene 配置，不能以更大编码换来的画质当作字典创新。用验证集预先定义相对于 B1 的可接受质量损失，再锁定测试；本协议不编造一个适用于所有任务的阈值。

## 3. 分阶段训练，避免一开始叠加全部损失

第一阶段：训练强密集条件生成路径。

第二阶段：以密集空间条件为教师，训练系数网络和字典重建这些条件，再用去噪/flow 目标联合训练字典、系数网络与适配器。损失起点是

\[\mathcal L=\mathcal L_{\mathrm{denoise/flow}}+
\lambda_c\|C_{\mathrm{gene}}-\operatorname{stopgrad}(C_{\mathrm{dense}})\|^2+
\lambda_s\mathcal R(A).\]

Top-k 和 L1 不需要不加区分地同时很强；按验证曲线选择。字典列单位范数以固定尺度歧义，统计 dead genes/激活分布并处理失活条目；不强求每个 Gene 使用均匀，也不强制所有向量正交。辅助项逐项消融。

第三阶段：仅在重建质量可接受后，小权重加入局部编辑/复用约束。每新增约束同时检查质量是否下降。感知损失可以用于重建或低噪声预测分支，但不在未说明的单步 x0 估计上代替完整采样质量评价。

## 4. 对 Gene 做最低必要的干预验证

固定原条件与采样噪声，逐一做：条件置零、整组跨图替换、局部系数移植、单 Gene 系数小幅扫描、字典条目置换。每个操作都记录原样输出及失败例。

系数扫描采用验证集观测到的合理分位范围；不把任意大幅度编辑视为保证有效。同一个 Gene 的操作跨场景比较，但允许上下文差异。局部移植不等同于独立语义因素迁移。

编辑区外变化与编辑区内变化同时报告，避免模型通过什么也不改得到高保持分。若设显式空间门控，说明局部性来自结构施加，不能据此声称自动解耦。编辑相同噪声至少多次重复；原/编辑对内共用噪声，跨对使用预先固定的一组不同噪声。

如果保留逐棵树需求，再加单树评价与对象绑定支线。空间网格 Gene 模型不能直接宣称逐实例控制。

## 5. 最后训练 Gene 先验，实现无源图采样

冻结或缓慢适配已验证的表示与渲染器，学习空间系数/索引的联合分布 p(A)。采用适合稀疏支持与系数结构的 masked/自回归先验或潜空间扩散；单独评价先验的成本。不要对稀疏索引和系数直接加入普通高斯就默认得到有效表示。

比较真实图片编码 A_real→生成器与先验 A_sample→同一生成器：前者好而后者差时，问题在表示分布建模。新组合先采用来自真实编码的局部受限重组；随机排列所有系数不作为预期有效的主要方案。

## 数据、评价与复现

建议预算（尚未清点为可用样本数）：先 2,000 张训练图做条件接口诊断，再扩展到 10,000–30,000 张训练图；独立验证约 2,000 张、同域测试约 2,000 张、未见城市测试约 2,000 张。实际数量由可用数据清单确定，不填充合成计数。

按全景、地理邻近关系和可获取的采集序列分组划分，再按城市留出跨域测试。源图哈希与感知近重复检查；不能只凭不同全景 ID 判定无泄漏。原四向全景不等于四个独立训练场景。测试不参与字典、归一化、超参数或主干选择。

条件重建：LPIPS、SSIM/PSNR、固定图像视觉检查、独立内容对应评价。DINOv3 可以是内容指标之一，但当其参与训练时不能是唯一评价器。

全新采样：等样本数 FID/KID、盲评自然度、多样性、最近邻检索以检查记忆复制。数千张及以上按预算报告样本规模；KID 给子样本不确定性，FID 仅在样本量/预处理一致下比较。不同指标对应不同问题，不合并成未经定义的“生成效果分数”。

编辑：修改区域内效果显著性、区域外保持、跨图一致性、生成自然度；评价器尽量独立于训练目标。盲评原/编辑对顺序随机化，画质与内容对应分别提问。

先对所有方案做一个固定随机种子的筛选，最终两个候选再做三种训练随机种子。每张输入至少四个预先固定采样噪声，报告全部或均值，不挑最好的一次。采样步数、guidance、分辨率、图像数和细化设置同时公开，预算内可调但只用验证集。
