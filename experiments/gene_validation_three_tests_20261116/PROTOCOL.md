# 城市视觉基因：三项验证实验

本轮目录：`/host/mnt/nas/urban-visual-gene/gene_validation_three_tests_20261116`。
原实验只读复用：`/host/mnt/nas/urban-visual-gene/residual_ista_gene_10k_scratch_20261116`。
所有模型训练和推理只使用空闲、已获取租约的 GPU，最多四卡、每个训练模型两卡。无 GPU 时排队。不会覆盖旧实验。

## 要检验的三个命题

1. 在相同的信息预算下，可学习字典比随机固定字典或普通多尺度 AE 更有效。
2. 相同基因/基因组跨图片产生稳定、可重复的干预效果。
3. 来自不同图片的基因表达可以被组合，并转入供体信息，同时保留接收图的其他部分。

重建好只能说明编码与解码有效；这三个命题还需分别提供证据。本轮也允许得到否定结果。

## 数据与样本隔离

- 三种训练方法都复用同一批 10,000 张真实街景、1,000 张验证图、1,000 张原测试图；分辨率 256×256，完整图片 RGB/Bicubic 缩放。
- 各 split 按格网、全景和图片隔离，原 split 不保证城市隔离。
- 从验证集中预选 64 个不同全景，供选择基因组、估计干预方向；不根据生成质量重选。
- 另从原百万图清单中按洲轮转选 128 个新城市；扫描时每城保留源清单前至多 80 张，再从该候选框内随机选一张。因此不是对每城全部图片的均匀抽样，也不把样本均值当作全球总体估计。其城市、格网、全景、图片均与旧实验所有 split 隔离。名单在模型推理前保存。
- 新城市来自亚洲、欧洲、北美洲、南美洲；这部分结论不覆盖非洲和大洋洲。城市名单见 `data/confirmation_selection.json`。
- 不复制 NAS 原始照片、不校验原图哈希。仅在 `/workspace` 创建可重建 RGB 缓存。
- 对照训练只按验证集选 checkpoint。原测试集已被历史实验查看，须称为固定测试集；新城市样本在本轮诊断后也不再是后续调参的盲测集。

## 实验一：相同字节预算的重建对照

### 三种模型

- `learned`：自训练多尺度 CNN → 六步非负 ISTA → 可学习多尺度字典 → 共享结构 RGB decoder。
- `random`：相同网络和初始化，字典从初始化起冻结，encoder、推断步长、decoder 重新训练。不是在旧权重上临时替换字典。
- `dense`：相同 encoder/decoder 主干、无字典、连续有符号通道瓶颈，通过 1×1 卷积映射至 decoder 的 64 通道特征。为覆盖三档预算，使用嵌套通道宽度的多码率 AE；不是在既有模型上事后剪枝。

两种字典模型的每尺度基因数为 256/128/128，核大小为 1/3/3，特征图为 16²/32²/64²。三者 encoder/decoder 主干在同一 seed 下初始化完全相同，全部从头训练；LPIPS 使用固定的预训练 AlexNet 作为度量/损失网络。

### 实际编码预算

|档位|每尺度空间位置对应的稀疏容量|AE 通道数|三尺度总编码字节|
|---|---:|---:|---:|
|低|1|3|32,352|
|中|4|12|129,120|
|高|16|48|516,192|

- 字典编码：每尺度全局 TopK，K=该尺度 H×W×表中容量，非负系数量上限分别为 5,376 / 21,504 / 86,016。
- 每个稀疏槽包含 uint32 展平索引 + float16 数值，共 6 字节；零值仍占固定容量，不能虚报缩小的字节数。
- AE 编码：每个保留的通道值占 float16 两字节；三尺度共享相同通道预算。
- 每尺度均有 32 字节头（形状、容量、类型），共 96 字节，已计入上表。
- 实际序列化/反序列化见 `source/codec.py`；GPU 测试验证字节数相等和码重放。训练前向也使用 FP16 舍入，反向采用直通梯度；实际重建从舍入后的码生成。
- 字典/网络权重假定是双方已共享的模型，不计入单张图片码长；额外报告模型参数与计算量。
- 高档码长超过原始 256² RGB uint8 的 196,608 字节。这是在检验表示效率，不能把高档结果宣称为优于原图的压缩。
- 这种固定索引编码不是最佳熵编码；正式压缩论文还应比较率失真编码器和熵模型。

### 训练与选优

- 随机种子 42、137，共六次独立从头训练；每个模型轮换三档预算，每三步各一档。
- 每次训练 6,000 更新，global batch 256，每卡 microbatch 128；每档经历 2,000 更新，所有模型数据流与更新次数一致。
- AdamW、初始学习率 2e-4，100 步 warmup，余弦降至 2e-5；沿用中细尺度门控渐进开启。
- 三者统一损失：L1 + 0.1 LPIPS + 0.05 归一化多尺度残差辅助损失。为隔离瓶颈作用，本组控制实验关闭原字典特征拟合辅助损失；不拿本组数值直接归因于旧模型单项变化。
- 每 500 步验证，第一次在 100 步；按三档验证 L1+0.1LPIPS 的等权平均选一个 checkpoint，不为每个测试档位另挑权重。
- 训练日志均值混合了三档训练损失，率失真分析必须使用验证/测试中分档记录。
- 输出每档 L1、PSNR、SSIM、LPIPS、真实码长、非零数、模型参数和 MACs；分别展示两个 seed，不把仅两个 seed 包装成强显著性结论。

支持标准：同字节下 learned 稳定优于 random/dense。若随机字典接近 learned，则学到的字典本身的额外价值不足；若 AE 更好，说明稀疏机制至少没有带来重建效率优势。

## 实验二：冻结编码的跨图片干预

令 A 为图像编码、D 为字典、G 为选择的基因集合：

`A'_G = alpha * A_G; A'_{not G} = A_{not G}; alpha ∈ {0, 0.5, 1, 1.5}`。

冻结 encoder、字典、decoder；编辑时禁止重编码、禁止 decoder 补偿。最终图像是各尺度线性合成特征经非线性 decoder 的输出，单基因 RGB 图不能相加解释。

- 在 64 张发现图中按系数 RMS 选每尺度最活跃的两个单基因和 top8 组，共九个目标。这里只选择“作用可测”的基因，并没有筛出人类语义。
- 在 128 个独立新城市上测试每个目标；图例固定显示前四张，不按好坏挑选。
- 对照是同尺度、发现集系数质量最接近的不同基因/组，确定性选择，并非随机抽样；逐图匹配特征贡献 L2 强度。
- 测亮度、红绿/蓝绿差、对比度、边缘能量、色彩幅度、上下/左右亮度差八个低层属性。按发现集自然属性标准差归一化。
- 目标组和匹配对照各自在发现集估计方向，再分别测新城市上的方向一致性、删除/增强一致性、剂量单调性、变化幅度、空间集中性。
- 另报告其他基因组与目标方向的对齐，但“其他组方向不同”不等于“其他组没有稳定功能”。
- 以城市为独立单位 bootstrap 2,000 次得到描述性区间；九个目标的结果是探索性证据，不据此作未校正的多重显著性断言。

支持标准：作用幅度可测、方向和剂量响应稳定，且效果不只是所有组都能产生的通用颜色偏移。低层属性稳定不等于对象级语义解耦。

## 实验三：固定基因码的组合泛化

`A_mix = A_A + alpha * M * (A_B,G - A_A,G)`。

- 128 张新城市图按原图低分辨率亮度布局和纵向 RGB 轮廓作确定性贪心匹配，固定 32 对不同城市 A/B，不根据混合结果调整配对。
- 保持 A 的粗尺度；把 B 中/细尺度所选基因组的中心区域表达替换到 A。M 为中间 1/2×1/2 的区域。
- 旧模型即时诊断比较：目标 top8 组、相似质量的其他组、同模型全部特征通道混合、RGB 局部 50% 混合。全部特征通道来自旧字典模型，不能冒充普通 AE。
- 新六模型训练完成后自动补充同码率的 learned/random/dense 编码混合对照，另在非目标基因中用固定 RNG 均匀抽取随机组（与即时诊断中的确定性匹配组区分）；alpha=0.25/0.5/1 形成迁移程度与区域外扰动的曲线。
- 检验自交换为恒等操作、稀疏混合码直接重放等于基因贡献之和的重放、粗尺度不变。
- 测中心内部对 B 的距离改善、LPIPS 变化和边缘 halo 之外对 A 的保留。比较各方法的自身完整重建基线，并同时保存相对真实照片的度量。
- RGB 混合天然有更小的像素距离，是参照，不以该指标断言它更逼真。组合没有唯一 ground truth，不能仅凭接近 A 的 PSNR 判断成败。
- GroupNorm 和 decoder 感受野会让局部编辑影响远处；区域外指标留出 32 像素缓冲区，但不保证隔离。
- 输出所有图、匿名评审材料和映射表；没有实际人工评审前不产生“人工真实性得分”。

支持标准：可观测且有选择性的 B 信息迁移，同时保留 A 的上下文，并在匹配扰动下优于随机/AE 混合。弱的全图颜色变化不能作为“树或建筑被移植”的证据。

## 运行、结果与有效性检查

- `source/supervisor.py` 持久训练队列，`queue_status.json` 状态，`runs/*/progress.json` 进度。
- `source/diagnose_genes.py` 旧权重即时诊断，`reports/frozen_diagnostics/` 输出。
- `source/postprocess_controls.py` 等六模型完成后获取空闲 GPU，补齐三模型组合对照并生成汇总。
- `reports/frozen_diagnostics/checkpoint_verification.json` 必须确认所有模型张量与 checkpoint 相等，并通过已知图像的重建质量检查。
- `reports/INVALID_unloaded_checkpoint_diagnostics/` 为权重加载遗漏期间的无效调试输出，明确排除，不可用于结论。
- CPU 仅做数据准备、编解码单测、统计和绘图。GPU 单测包含码重放、三档预算、冻结与梯度、初始化匹配；双卡 smoke 包含梯度等价、真实图过拟合、完整 batch、rank 参数同步。测试模型权重不用于正式训练。
- 根文件系统没有空间；持久资料全部写 NAS，临时文件与缓存写 `/workspace`。
