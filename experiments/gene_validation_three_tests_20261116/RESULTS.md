# 城市视觉基因三项验证结果

更新：2026-11-17 01:39:09 北京时间。正式诊断已严格加载 step 6000 权重；已知图片回归检查通过。

## 当前判断

- 新城市重建：128 个独立城市，平均 PSNR 30.78 dB，SSIM 0.8968，MAE 0.01941。支持重建泛化。
- 干预：不少基因/组产生稳定的低层视觉变化，但相似质量的其他基因组也很稳定；这不构成城市语义或独立生成单元的充分证据。
- 组合：选定基因组的迁移弱，未显示优于其他基因组。全部特征混合能移入中心图案，但会出现明显的拼接边界。当前只能确认编码可编辑，尚不能确认有自然、选择性的“城市视觉基因组合”。
- 相同编码字节预算的六次训练已完成，分档结果见下表。重建对照也不能替代基因组合验证。

## 实验一：同编码预算对照

三方法 learned / frozen-random / dense，多码率 32,352 / 129,120 / 516,192 字节，两个 seed，共六次训练，每次 6,000 更新、global batch 256。每三步覆盖一轮三档预算，每档实际训练 2,000 更新。网络权重共享后不计入单图码长，稀疏索引和固定容量填充已计入。高档码长超过原始 uint8 RGB，不能宣称图像压缩优势。

## 实验二：跨城市干预

发现集 64 张固定选择：每尺度两个单基因 + top8 组；确认集 128 个新城市。alpha 为 0、0.5、1、1.5。匹配对照使用不同基因且匹配特征贡献强度，每组各自在发现集估计变化方向。下表为组级结果，完整九目标和逐图数据见 JSON。

|尺度|组|增强变化 MAE|增强方向余弦|剂量单调比例|
|---|---|---:|---:|---:|
|coarse|选定组|0.00565|0.821|99.2%|
|coarse|匹配其他基因组|0.01200|0.847|88.3%|
|medium|选定组|0.00500|0.974|75.0%|
|medium|匹配其他基因组|0.00507|0.937|34.4%|
|fine|选定组|0.00858|0.992|100.0%|
|fine|匹配其他基因组|0.00584|0.961|100.0%|

方向余弦衡量亮度、颜色差、对比度、边缘等八个属性，不表示树、建筑等语义。高余弦可能由单一亮度方向主导。删除与增强的方向一致性在部分中尺度组较差；完整记录中保留该失败。其他基因组也能有稳定方向，不能据此排除通用特征分解。

## 实验三：A/B 组合

保留 A 粗尺度，替换中心中/细尺度的 top8 基因表达；32 对不同新城市，配对由原图低层布局决定。局部向 B 靠近幅度定义为 `(编辑前到B的MAE - 编辑后到B的MAE) / 编辑前到B的MAE`，基线使用各自完整重建。中心指标避开边界，区域外指标排除 32px halo。

|方式|局部向 B 靠近幅度|95% 描述性区间|区域外变化 MAE|
|---|---:|---|---:|
|选定基因组|2.35%|[2.21%, 2.49%]|0.000203|
|匹配的其他基因组|2.77%|[2.59%, 2.95%]|0.000212|
|旧字典模型全部特征通道|88.83%|[87.27%, 90.16%]|0.004319|
|50% 局部 RGB 混合|50.00%|[50.00%, 50.00%]|0.000000|

选定组减其他基因组的逐对差值均值为 -0.41%，bootstrap 95% 区间 [-0.50%, -0.33%]。该差值仍受组贡献幅度差异影响，不能直接当作因果优劣。

选定基因组变化小，没有出现清晰的对象级迁移；其他基因组的变化也小。全部通道混合接近在区域内替换图像，供体距离下降更大，但有边界伪影，不能称为自然组合。RGB 混合的 50% 距离改善由其定义决定，不能据此判断视觉真实性。

这里的“全部特征通道”来自旧字典模型，并非普通 AE。新六模型的普通 AE 等组合对照已补齐，见 reports/trained_composition_controls.json 与以下曲线。

## 对研究主张的含义

目前更稳妥的说法是：学到了一套能够重建街景的多尺度加性特征。要进一步称为城市视觉基因，需要在相同信息预算对照和可观测的组合迁移上提供额外优势。稀疏竞争或重建目标本身不保证对象/语义解耦，也不保证混合码位于训练分布内。
