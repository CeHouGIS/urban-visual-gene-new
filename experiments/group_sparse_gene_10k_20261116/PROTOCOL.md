# 可复用的加性视觉基因：10k 初版实验

2026-11-17 根据用户明确的研究定义修订：**可组合即特征可加；跨图可复用是首要目标，少量是次要目标。** 研究问题改为：能否学习一套固定的加性视觉基因，使相同基因在不同街景、不同城市中反复帮助重建，再评估能否进一步减少数量。

特征线性相加是结构性质，不以局部RGB移植是否自然作为主成功标准；基因也不要求有树、建筑等可命名语义。既有局部组合结果作为历史诊断保留。原方案及源代码已备份至 `revisions/20261117_reuse_priority/before/`，修订时新实验尚未进行任何GPU测试或主训练。

本目录是独立实验。代码、配置、日志、checkpoint 和结果存放在 NAS；RGB 数组与临时文件复用服务器本地缓存。原实验目录、队列和 checkpoint 保留。

## 1. 解决的问题

先前系数稀疏并没有保证整张表达图稀疏：一个基因只要还有一个非零位置，就仍被调用；高分辨率表达图本身也可能携带大量图像细节。因此，“重建好”或“部分系数为零”不足以支持发现少量可复用基因。

同一字典被所有图共享只是结构上的共享；同一基因频繁非零是反复激活；只有同一固定基因在多张图中对重建有实际贡献，才提供有效复用证据。不能用强制均衡激活频率代替验证。

先以64个整基因上限作为较宽的主档，维持有限表达容量；再用32/16/8档研究减少数量的代价。64是初步容量选择，不是已发现64个自然基因，也不是容量最优的结论。报告两个不同统计量：

- **每图调用数**：一张图有多少张表达图在量化后仍非零。
- **全数据集字典使用数**：在所有图中至少使用过一次的不同基因有多少个。共享库仍有 512 个候选基因；每图使用少不等于全数据集只使用少数基因。

## 2. 模型与加性的位置

从头训练 CNN 编码器，输出三个尺度的特征。每个尺度有表达头和整基因选择器：

\[
R_s(x)=4\,\sigma(H_s(E_s(x))),\qquad
\ell_s(x)=W_s\operatorname{GAP}(E_s(x))+b_s.
\]

表达头先将特征平均池化到较小网格。选择器根据整张图的特征为每个基因打分。训练时采用 hard-concrete 随机门控；评估时采用确定性门控。每个尺度只保留分数最高的至多 \(k_s\) 个候选：

\[
A_{s,g}(x)=Q_8\!\left[R_{s,g}(x)\,h_{s,g}(x)
\mathbf 1\{g\in\operatorname{TopK}(\ell_s,k_s)\}\right].
\]

\(Q_8(v)=\frac4{255}\operatorname{round}(255\operatorname{clip}(v/4,0,1))\)。整基因关闭时，它的整张表达图变成零。量化也可能让一张表达图全部归零，因此实际使用数可以小于上限。

每个尺度用共享且归一化的卷积字典合成特征，之后通过非线性 decoder 重建 RGB：

\[
F_s(x)=\sum_g D_{s,g}*\operatorname{Up}_2(A_{s,g}(x)),
\qquad \widehat x=\operatorname{Decode}(F_c,F_m,F_f).
\]

加性严格发生在尺度内的**特征合成**处；单独 decode 的 RGB 图像相加通常不等于完整重建。编码器特征没有直接绕过字典进入 decoder。

与之前 ISTA 版本相比，本实验有意改为 **CNN 直接预测有界表达图和选择分数**，不再进行展开 ISTA。主要目的是让整组支持、低分辨率表达与真实量化共同参与训练。因此，新旧结果的差异不能全部归因于整基因门控；本实验内部 learned/random 对照才用于检验字典学习的价值。

训练中对 TopK 与量化采用直通梯度估计。未被选中的候选选择器也获得软门控梯度，帮助支持集合变化；前向传播仍严格执行整图清零与 8 位量化。这是离散选择的近似梯度，并非精确离散优化。

## 3. 三个尺度与真实码量

输入为 256×256 RGB。三个尺度的基因身份独立，合计 512 个候选。

|尺度|候选基因数|字典核|合成特征大小|传输表达图大小|表达范围|
|---|---:|---:|---:|---:|---|
|粗|256|1×1|64×16×16|8×8|[0,4]，uint8|
|中|128|3×3|64×32×32|16×16|[0,4]，uint8|
|细|128|3×3|64×64×64|32×32|[0,4]，uint8|

|整图调用上限|粗/中/细配额|最大编码字节/图|
|---:|---|---:|
|8|4 / 2 / 2|2,928|
|16|8 / 4 / 4|5,760|
|32|16 / 8 / 8|11,424|
|64|32 / 16 / 16|22,752|

每个尺度使用 32 字节文件头；每个实际非零基因传输 uint16 编号及固定大小的 uint8 表达图。实际字节数为：

\[
B(x)=96+\sum_s n_s(x)(2+H_sW_s).
\]

不另传门控值或图像相关幅度；它们的效果已量化到表达图中。字典、decoder、表达上限与量化规则属于共享模型，以上字节数不包含共享模型权重。该计数是当前未熵编码的文件格式长度，不是信息论最优码率。

## 4. 数据与对照

- 训练 10,000 张，验证 1,000 张，测试 1,000 张真实街景，复用原有固定划分与 RGB 缓存。
- 训练集保留 1 km 格网，每格 5 个全景点，每点 4 个方向，合计 20 张。每个全局 batch 从不同格网取图，降低同一批中邻近视图重复。
- 另复用 128 个不同城市各一张的诊断集。它与原训练/验证/测试的城市、图像、全景点和格网不重合，但之前已经查看过，**不能当成新的盲测**。
- 两个随机种子：42、137。每个种子训练 learned 字典与 frozen-random 字典各一个，共 4 个模型。
- 同种子的两个模型初始数值完全相同，仅 random 模型的字典从初始化起冻结。编码器、选择器、表达头与 decoder 均照常训练；数据顺序、损失与更新预算相同。
- 每8次更新依次使用上限64、64、64、64、32、32、16、8，共8,000更新；64档4,000次，32档2,000次，16/8档各1,000次。主档先保证表达容量，少量属于次要探索。评估同一checkpoint的全部四档，按64档验证目标选优。

## 5. 训练目标与调度

\[
\mathcal L=\mathcal L_{L1}+0.1\mathcal L_{LPIPS}
+0.05\mathcal L_{pyramid}.
\]

本轮显式基因数量价格与字节价格设为0，避免将训练主压力放在继续减少调用上；整基因上限、有界低分辨率表达图、真实8位量化继续限制信息容量。复用通过全数据集共享字典和重建目标学习，再在未见城市上用冻结权重的干预来检验；并未加入强制高调用率或均匀使用的损失。

金字塔辅助目标为粗图像、中尺度 RGB 残差、细尺度 RGB 残差，并按各图目标 RMS 归一化。它鼓励尺度分工，不能证明各尺度严格独立。

日志保留 hard-concrete 在 **TopK 截断与量化之前**的非零概率和预期复杂度，当前不将它作为有权重的训练惩罚：

\[
P(h_{s,g}>0)=\sigma\!\left(\ell_{s,g}-\beta\log(-\gamma/\zeta)\right),
\quad \beta=2/3,\ \gamma=-0.1,\ \zeta=1.1.
\]

这个期望是随机训练门控的解析量，给出截断和量化后训练码量期望的上界；它不是确定性评估的真实调用数。评估必须统计量化之后的非零图，并核对二进制文件长度。

- 初始非零概率 0.9。
- 中尺度从更新 200 到 600 渐入；细尺度从 600 到 1,200 渐入。
- 更新 400 到 1,600 将候选配额从整库逐渐收紧到目标，同时渐入随机门控。**早期训练并不满足最终每图上限**；验证/测试始终使用最终上限。
- 原复杂度惩罚实现与调度保留供后续消融，当前价格为0，不生效。
- AdamW，学习率 2e-4 → 2e-5，预热 100 更新，梯度裁剪 1.0。
- 每模型两张 GPU，全局 batch 256，每卡 microbatch 128；最多同时运行两个模型，合计四卡。
- 共 2,048,000 次图像呈现/模型，相当于 10k 训练集约 204.8 遍，不是 204.8 万张不同图像。
- 每500更新验证，首次在100更新；按主档64的验证RGB目标选最佳checkpoint。其余档位和四档平均值分别记录，不用小容量档位决定主模型选优。每100更新保存恢复点，恢复随机状态和优化器状态。

## 6. 通过什么证据判断

1. **首要：有效跨城市复用**。固定编码器、字典与decoder全部权重，在主档64对128个固定城市图像的每个已激活基因逐一删除，其他表达码保持不变。记录删除带来的重建MAE增量、正负效果和RGB变化。相同基因在至少2个不同城市产生实质重建贡献，记为描述性的反复有益；另外报告是否覆盖至少2个国家及覆盖多少大洲。
2. **区分反复激活与有益复用**。逐基因激活频率与有益城市数分别报告。有益的预设描述阈值为删除后的MAE增量同时超过原误差1%和1e-5，并保留完整连续增量及负效果。这是可检查的操作定义，不是统计显著性，也不是语义或因果身份的证明。只频繁激活但删除无影响的基因不计为有益复用。
3. **质量与学习的额外价值**。报告主档和其余档的L1、PSNR、SSIM、LPIPS及实际字节数。learned/random比较回答学习字典相对随机固定字典有没有额外优势；随机字典本身也可能复用，所以random更好不直接否定可复用。两个种子分别展示。
4. **次要：数量精简**。报告各档实际每图调用数、全数据集使用过的基因总数、调用分布熵与质量代价。少量不是主实验的先决成功条件，512个共享基因中使用较多也不自动判失败。
5. **可加性与真实码重放**。各尺度的线性字典合成由结构保证特征可加，再用数值重放检查。严格加载checkpoint、保存并重放真实.bin，检查无隐藏编码旁路，验证随机字典不变。单独RGB解码通常不可相加，这不改变本项目对特征可加性的定义。
6. **次要删除例图**。保留上限8档前16张诊断图逐基因删除作为小容量对照；主复用结论来自64档全部128城市的完整统计。例图选影响最大的删除，不能取代完整统计。

主结论围绕固定的加性基因能否在不同街景中反复起作用。相对random的优势是学习字典额外价值的独立问题；语义命名、自然RGB局部移植不属于本轮必要条件。若频繁激活却无有益删除效应，说明当前证据只支持结构共享；若在多个城市有益，支持操作定义下的有效复用，之后再研究进一步精简。

单基因删除测量的是其他表达保持固定时的条件贡献。相互冗余或可替代的基因可能被低估，因此无明显删除效应不能直接证明不存在复用；必要时再通过整组删除或保留部分字典后的表达重估检验冗余。当前不把有益基因计数解释为全部真实可复用基因的精确数量。

## 7. 执行顺序与产物

1. CPU 仅运行 codec、配置、数据流和依赖状态测试，不运行神经网络。
2. 排队等待原三项验证实验的训练及后处理全部结束。
3. 获得空闲且已加共享锁的 GPU 后，运行 GPU 模型测试；通过后每模型先做双卡梯度一致性、真实四图过拟合和完整 batch 冒烟测试。冒烟权重丢弃，主训练重新初始化。
4. 主训练完成后评估固定测试集和已使用过的城市诊断集。
5. 在空闲 GPU 上进行严格码重放、复用与逐基因删除审计，全部完成才将总队列标记为 complete。

关键位置：

- `configs/experiment.json`：完整固定参数。
- `queue_status.json`：队列状态、依赖、活动任务和 GPU。
- `reports/cpu_tests.xml`、`reports/gpu_model_tests.xml`：真实测试报告。
- `reports/<variant>.distributed_smoke.json`：双卡检查与峰值显存。
- `runs/<variant>/history.jsonl`、`validation_history.jsonl`、`loss_curves.png`：训练和验证曲线。训练日志的滑动均值混合不同配额；各档比较使用验证记录。
- `runs/<variant>/checkpoint_resume.pt`、`checkpoint_best.pt`：恢复点与验证选优 checkpoint。
- `runs/<variant>/previews/`：原图、四档重建、调用上限为 8 时的误差图及真实编码例子。
- `reports/gene_quality_budget_curves.png`、`RESULTS.md`：结果比较。
- `reports/gene_audit/`、`reports/final_audit_status.json`：训练后 GPU 审计。
- `reports/gene_audit/<variant>/functional_reuse_summary.json`、`functional_reuse_deletions.json`：主档128城市全部活跃基因的删除与复用统计；`functional_reuse_progress.json`记录审计进度。

仅停止本实验时，在本目录创建 `STOP_REQUESTED`。不修改原实验队列。若 GPU 不可用，本实验保持排队，不切换到 CPU。
