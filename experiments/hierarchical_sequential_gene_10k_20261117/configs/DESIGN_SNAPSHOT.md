# 数据驱动的四层视觉基因：先学习差异，再验证功能

日期：2026-11-17。状态：研究设计建议，尚未实现或训练。

本方案回应“能否通过 data-driven 的方式学习不同层次的信息差异”。保留 V2/V3 作为历史参考；不把各层的语义功能预先定义为既成结果。

当前修订：根据用户要求，移除每单元覆盖原图 2×2 像素的 L4 微细节层。当前模型只有 L0—L3 四层，不保留独立像素级分支或该层的零均值约束。

Loss 简化修订：首轮仅使用同一种多尺度 L1 重建目标与量化承诺项。容量由固定字典大小和索引槽数约束，不再加入 Rate loss、独立加权的前缀辅助项或语义分工 loss；LPIPS 首轮仅作评价指标。

顺序重建修订：编码和解码固定按 L0→L1→L2→L3 执行。每个细层在实际父层重建完成后，编码其剩余误差，再把局部修正加回父层图像；不使用真实低分辨率图替代预测父层。

## 1. 可以学习什么

模型可以通过不同范围、不同信息预算和跨样本变化，学习各层不同的统计作用。仅有 RGB 重建目标时，同样好的重建可能对应多种不同的信息分配；不能保证自然出现唯一的“氛围—布局—纹理”分解。

因此区分两个问题：

- 发现：只给尺度、局部支持、容量和重建任务，各层实际学到什么？
- 引导：给同一场景的已知变化关系，能否让功能更接近预期？

第一轮先做发现版，以变化响应和编码交换给层级命名。若需要更明确的绘画分工，再做自监督引导版。两者的先验与证据分别报告。

## 2. 保留空间约束，取消专用语义输出头

保留四层：全画布、2×2 格网、4×4 格网、8×8 格网。对 256×256 RGB 输入，候选配置如下：

|层级|整图格网|单元数|每单元覆盖原图|原生输出分辨率|共享字典大小 K|每单元索引槽数 R|
|---|---|---:|---|---|---:|---:|
|L0|1×1|1|256×256|32×32|64|4|
|L1|2×2|4|128×128|64×64|128|4|
|L2|4×4|16|64×64|128×128|128|4|
|L3|8×8|64|32×32|256×256|256|4|
|合计|—|85|—|—|576|340 次索引调用/图|

各层原生 patch 均为 32×32。L3 直接生成完整 256×256 输出所需的局部修正，承担移除 L4 后剩余的细节表达；不是先停在 128×128 再增加隐藏的微细节支路。
原生输出分辨率统一为 32/64/128/256，这与历史五层方案的 16/32/64/128/256 有区别，需记录在配置与对照中。

发现版不使用 V3 的专用全局光度头、强制轮廓头、区域调色板渲染器。各层使用可学习的局部字典表示与条件解码器，函数形式类似、参数分层共享。
只固定支持范围、粗细分辨率、逐图码量和父子条件关系，不预先给字典原子命名。

先重建 32×32 底稿，再依次到 64×64、128×128、256×256。L0 编码/重建 x_0；对 l=1..3，先取得已经解码的上一层输出：

    parent_l = Up(x_hat_(l-1))
    residual_l = x_l - parent_l
    q_l,j = Quantize_l(Encode_l(Crop_j(residual_l), Crop_j(parent_l)))
    delta_l,j = Decode_l(q_l,j, Crop_j(parent_l))
    x_hat_l = parent_l + sum_j Place(delta_l,j)

这使细层编码针对实际重建中尚未表达好的部分。原图只用于编码器计算残差和训练目标，解码端只有字典索引和解码出的父上下文。
必须先得到 x_hat_(l-1)，才能构造下一层编码与重建。同一层的单元可以并行计算，不改变层级之间的顺序。解码已有索引时也必须按相同顺序取得父上下文。

固定目标金字塔为 32/64/128/256，使用与预测相同的 Up。真实目标的拉普拉斯残差用于金字塔重放协议检查，实际训练的细层残差则基于预测父层，两者不能混淆。
局部修正允许正负值，中间预测不裁剪，以保留精确的加性关系；展示时的裁剪与评价范围处理单独记录。
首版使用 bilinear、align_corners=False，局部允许影响范围包含已知的有限插值边缘，测试中明确计算；不把影响范围误称为绝不超过名义格子。
父上下文只能来自已经量化的粗层代码；没有直接送入解码器的原图、高分辨率 skip 或额外风格码。
每个局部输出的最终支持仍受预定义窗口及明确插值边缘限制，最终不接无界的全图精修网络。

这种结构让子层补充父层尚未表达的信息。字典原子可成为在父上下文中重复使用的修正方式；有父条件时，其最终 RGB 图样不是上下文无关的固定贴片。

先做逐层预训练：训练 L0 后冻结其编码器、解码器和码本 EMA，再训练 L1；按同样顺序启用 L2/L3。当前训练层不能反向改变已冻结的父层。冻结父层并不妨碍从其真实解码结果计算当前残差。
保存逐层训练完成的模型作为基线，之后才做小学习率联合微调，检验其质量收益及分工是否漂移。联合训练仍是顺序前向，不能改成四个独立分支各自重建完整图像。

## 3. 固定信息预算与简化 loss

粗层用少量代码影响大范围，细层用局部代码补充剩余信息。粗层可能优先表达对大量像素都有价值的信息，细层表达更局部的变化；这是一种偏向，不是语义保证。

逐层预训练时，只优化当前层 m，使用同一个简单目标：

    L_stage_m = mean(abs(x_hat_m-x_m)) + beta * L_commit_m

父层固定时，当前层的像素误差等价于其修正图与实际剩余残差的误差；无需再添加一项重复的 residual loss。
完成四层预训练后，联合微调阶段对四层相同重建规则等权平均，不再区分“最终重建项”与“前缀辅助项”：

    x_l = Down_to_(32,64,128,256)[l](x)
    L_recon = (1/4) * sum_(l=0..3) mean(abs(x_hat_l-x_l))
    L = L_recon + beta * L_commit

每项先按该层像素和通道取均值，避免 256×256 层因为像素多而在数值上自动占优。每层目标图像、固定升采样与金字塔构造保持一致。
联合阶段仍保留对各层前缀的监督，但只用一种重建准则和固定等权，不再引入单独的 eta。若只监督最终输出，粗层更容易被最后一层绕过，因此首轮不删去中间输出的重建检查。

量化采用直通估计与 EMA 码本更新。L_commit 为量化前特征与停止梯度的选中字典表示之间的均方误差；残差量化按各步实际残差目标计算，先平均层内单元、步骤和特征维度，再平均四层。
EMA 已负责更新码本，因此不再叠加梯度更新码本的另一套 codebook loss。beta 只控制编码特征贴近码本，候选初值 0.25，需在 smoke test 中确认特征尺度和两项损失量级，并非语义分工权重或已验证最优值。

逐层目标只要求前缀达到相应尺度的重建质量，不直接规定某层必须是树、道路或颜色。
这首先推动尺度分工，不能把低频保持自动解释为氛围保持。

首轮固定各层 K 和每单元 4 个索引槽，用架构限制逐图信息上界。不训练熵模型，不加入空码门控，也不把固定索引总位数作为可优化 loss；该总位数在本配置下是常数。
这一简化不主动学习最短编码，也不保证实际使用最少种 gene。字典复用及有用性仍通过跨图实例、删除和替换实验评价。

LPIPS 首轮记录为评价指标。仅用 L1 可能使细节偏平滑；若验证中出现这一问题，再单独增加感知重建对照，并报告额外项带来的变化，不自动向主方案追加其他 loss。

当前候选共有 576 种共享字典条目、85 个空间单元、340 次索引调用，三者含义不同。按固定长度索引保存时：

    bits = 1*4*6 + 4*4*7 + 16*4*7 + 64*4*8 = 2,632 bit
    bytes = 329 byte/图

这是首轮固定长度候选配置，不含共享字典/解码器权重和容器元信息，不作为已经实现熵压缩的结果。
四层候选的 L3 仍占约 77.8% 的固定索引位数，因此继续检查模型是否主要依靠最后一层，并绘制码率—质量曲线，不能把高质量直接解释为功能分工。
已移除原 L4 的每个 2×2 块减均值投影，不要求 L3 对原图每个 2×2 像素块保持均值不变。

## 4. 数据中提供哪些变化

### 现有单张街景即可构建的配对

1. 原图与轻微曝光/白平衡变化图：几何不变，光度改变。
2. 原图与已知翻转/几何变换图：空间关系按已知变换改变；材质也随位置移动，不能强制所有外观码逐位置不变。
3. 原图与轻度模糊或幅值有限的局部高频扰动图：测量各层对不同细节强度的响应，同时记录低通内容与轮廓实际发生的变化，不假定严格保持布局或某个平均图不变。

这些配对不需要人工物体标签，变化类型和关系由数据构造过程给出。它们引入了自监督先验，只能直接证明对这些变化的分工。
人工高频扰动不是自然材质变化，不能用它单独证明发现了“砖墙/树叶”等材质概念。

### 如果存在真实分组数据

- 同一位置、近似同视角的不同时间照片，更适合观察稳定结构与可变外观；需要配准，并处理移动物体、遮挡和真实结构变化。
- 当前采样设计中每个全景点的四个朝向，可以作为共同采集环境的弱分组。四个朝向的布局和可见物体不同，不作为结构相同的正样本。
- 跨城市重复出现的局部结构与纹理，用于检验字典复用，不把同一城市的所有照片强制视为同一氛围。

不假定这些重复时间数据已经存在。第一轮可直接从现有 10k 街景及已知变换开始。

## 5. 发现版与自监督引导版分开

### A：发现版，首选起步实验

仅使用四层等权 L1 重建与 EMA 量化承诺项，编码预算由固定结构限制，不添加按语义分配给特定层的一致性 loss。
训练后在独立验证子集上测量各层对上述变化的响应，观察是否形成稳定分工。
允许出现“两层都承担结构”“粗层同时承担布局和颜色”的结果，按观察描述，不强行把每层命名为预设功能。

### B：自监督引导版

保留 A 的解码结构，增加已知配对变化的一致性/组合重建。
例如光度变化对 (x,Tx)，保持候选结构层代码，替换候选光度层代码，要求重建 Tx；这是有明确目标的训练，不需要不存在的自然混合图 GT。

    q_mix = codes_from_Tx_on_subset_S + codes_from_x_on_other_layers
    L_pair = D(Decode(q_mix), Tx)

若预先指定 S，就明确这是层级功能的弱先验，不称为完全自主发现。也可依据训练内部划分上的响应选择候选 S，但必须固定后再在独立图像/城市评价，不能在测试集挑最有利分工。
首轮不加入复杂自动路由。只有 A 的结果显示功能混杂、且确实需要对齐预期时，才开展 B。
编码循环一致性不能作为唯一约束，防止模型通过共同编码技巧获得虚假的可交换性。

## 6. 如何判断不同层学到了什么

为四层分别制作“变化类型 × 层级”的响应图：曝光/白平衡、几何、细节变化分别影响哪些层。
原始代码距离受维数、单元数、数值尺度影响，不能直接跨层比较。至少按每单元、每维和训练集方差归一化，并同时测量解码后的效果。

逐层替换实验：

    x_mix_l = Decode(q_0(x), ..., q_l(Tx), ..., q_3(x)), l=0..3

报告它对目标 Tx 的误差改善、非目标结构/颜色改变及影响窗口。用完整 Tx 编码重建作参照，区分原有重建误差与交换误差。
条件解码存在层间交互，单层改善不一定相加为总改善，不能把响应图自动解释成唯一的因果分解。

同时检查：

- 前缀重建是否逐步恢复结构和细节。
- 每个细层展示同分辨率的原图目标、升采样父层、真实剩余残差、预测修正及新重建。误差比较必须在同一个当前分辨率进行，不能直接比较 32×32 和 256×256 的 MAE 来声称逐层改善。
- 记录每层修正前后的误差差值及变差样例；顺序相加本身不保证每张图每一步都会改善。
- 检查实际执行顺序、预测父层条件、加性恒等式和索引重放。冻结预训练阶段父层参数及 EMA 统计必须保持不变。
- 删除/替换各层对低通图、归一化轮廓、全局颜色和高频成分的影响。
- 分工是否在未见城市、不同随机种子上复现；仅原子 ID 置换不视为失败。
- 同一原子在不同图像/城市中的调用样例及实际作用是否一致。
- 去掉一个常用 gene 后是否产生稳定且有用的变化，而不只看使用频率。

低熵或高调用次数都不等于有意义的复用；仍需真实跨图样例和功能干预证据。

## 7. 最小实验顺序和结论边界

1. 在独立目录实现 A，10k 真实街景起步，与相同四层格网及相近码率的基线比较；GPU 不可用则排队，不用 CPU 进行神经网络训练或推理。
2. 固定按 L0→L1→L2→L3 编码/解码；训练时先逐层预训练并冻结已完成的父层及其 EMA，仅使用当前层的 L1＋commitment。每层达到预先设置的验证平台期或训练上限后，保存模型并进入下一层，不用训练集误差作为唯一切换标准。
3. 保存完整逐层训练基线，再做小学习率联合微调；联合阶段使用四层等权 L1＋commitment，前向始终保持顺序。不再安排 L4 分支或单独微细节阶段。比较联合微调前后的质量、前缀可用性与分工变化。
4. 先交付码率—质量、四层前缀图、逐层修正和误差变化、变化响应图、跨图复用图册。
5. 检查功能能否从数据中稳定形成，再决定是否运行 B。
6. 若以 V3 专用功能头作为更强先验的对照，同样移除其 L4 后再比较，报告码率与模型容量；历史五层结果不作为容量公平的证明。

可得出的结论是某些层稳定承载了某类变化、具有可复用作用。若只出现频率分工，就如实报告频率分工；不能因此宣称已经分离物体、氛围和材质。
本次仅保存方案，不启动实现或训练。
