# DINOv3 街景表示试验结果

后续修订（2026-10-11）：针对 RGB 输出过于模糊，已新增[生成方案重新设计](/root/code/urban-visual-gene/experiments/dinov3_generation_revision/DESIGN.md)与预训练 VAE 图像编解码对照。下一轮先验证预训练生成路径与 DINOv3 条件传递，再检验对象瓶颈；多视角一致性用于处理实例合并，不能单独修复当前 RGB 解码器的限制。下文保留本轮原始结果。

这轮轻量试验支持“从街景中学习图像相关的区域表示”，尚未达到“逐棵树形成独立编码，并通过编码实现形态与外观解耦的可控生成”。这不是对所有对象中心方法的否定，而是本次数据规模、架构和训练下的结果。

## 本次实际完成的工作

使用既有 DINOv3 ViT-L/16 patch 特征，训练新的 Slot Attention 与共享空间解码器，再冻结发现模型训练 RGB 重建器。训练不使用对象类别、框、实例 mask，也不使用已有 SAE 激活。

使用 512 张训练图、64 张验证图和 32 张未见城市测试图。训练与测试按全景隔离，源图 SHA256 无交集。输入为 448×448 对应的 28×28 特征网格，特征经训练集 PCA 压缩到 64 维，保留 75.35% 的方差。

完成了 16/32 slots 初始训练、延长训练并增强 RGB 重建器，以及去掉编码器显式坐标输入的对照。16/32-slot 改进版均累计约 80,000 次训练图像暴露；对照的完整历史仍不同。去坐标对照从已训练模型继续学习，不能把差异全部归因于坐标。最终模型由验证误差选择，跨城市数据不参与选择。

## 定量结果

特征 MSE 在训练集 PCA 空间计算，越低越好。平均布局基线对所有图像输出训练集的逐位置平均特征；它的同城市验证 MSE 为 0.521，跨城市为 0.502。

| 最终模型 | 验证特征 MSE | 跨城市特征 MSE | 验证 RGB PSNR | 换初始化后区域匹配 IoU |
| --- | ---: | ---: | ---: | ---: |
| 16 slots，延长训练 | 0.275 | 0.278 | 17.66 dB | 0.560 |
| 32 slots，延长训练 | 0.224 | 0.230 | 18.19 dB | 0.467 |
| 16 slots，编码器不加坐标 | 0.415 | 0.404 | 16.15 dB | 0.522 |

32-slot 模型的验证特征误差比平均布局基线低约 57%。将整组编码替换为其他图像的编码后，全部 96 张验证/测试图的特征 MSE 增至 0.744；原编码对应的同一组图像 MSE 约为 0.226。这说明模型确实利用了图像编码，但不能据此证明编码代表物理实例。

初始化稳定性在 16 张预先选定的验证图上计算，通过最优匹配消除 slot 编号置换，再按区域面积加权。数值不是实例分割准确率。只镜像缓存特征的匹配 IoU 分别为 0.539、0.510、0.766；并未在镜像原图上重新提取 DINOv3 特征。

32-slot 模型在 96 张图上平均有 29.10 个 slot 占据至少 1% 的 patch；16-slot 改进版为 14.96。这个数量不等于对象数，大面积天空和道路也会被拆成多份。

## 结果图与判读

下面每个城市展示预先固定的第一张验证/测试图，没有按效果挑选。颜色只表示图内 slot 编号，不是固定类别。

![三个分组方案的固定样本对照](/root/code/urban-visual-gene/experiments/object_centric_pilot/results/comparison.png)

可见几个尚未解决的问题：

- 多棵相邻树木仍可能共同落入一个区域。
- 同一物体也可能被分到不同区域；天空、道路出现明显的几何切分。
- 去掉分组阶段显式坐标没有形成稳定的独立对象；其每张测试图至少有一个占据区域的 slot 包含多个不连通部分。
- 改变初始化后的区域一致性不足，不能把一个 slot 当作稳定的景观单元身份。

![32-slot 方案的区域分组与 RGB 重建](/root/code/urban-visual-gene/experiments/object_centric_pilot/results/k32-refined/overview.png)

RGB 输出仅为小型网络的 112×112 重建，仍明显模糊。它提供外观恢复能力的诊断，没有验证高保真街景生成。

![跨图像替换 slot 的压力测试](/root/code/urban-visual-gene/experiments/object_centric_pilot/results/k32-refined/interventions.png)

替换单个 slot 会改变输出；固定原 mask 时，变化更多集中在指定区域。但这里选取的是无类别的占据区域，供体是距离较大的编码，并非“同一棵树只变树冠”的语义干预。固定 mask 的空间关联是主动施加的，不能当作模型已经学会形态/外观解耦的证据。卷积重建也会把部分变化扩散到区域附近。

全部 96 张验证/测试图保存在各结果目录的 `gallery_00.png` 至 `gallery_05.png`；每图诊断与编辑数值保存在 `per_image.json` 和 `metrics.json`。这里只对固定总览样本与编辑图做了视觉检查，没有对全部图像逐棵树人工判定。

## 对你的研究意味着什么

当前数据与训练能支撑一个区域表示的起点，还不能把这些 slots 直接定义为“每棵树的视觉基因”。仅提高槽位数量、延长重建训练或去掉坐标都没有在本轮建立所需的实例粒度。

下一轮最值得补的是无实例标签的对象一致性信号，例如同一实体在视频或重叠多视角中保持身份，并把这种一致性与局部形态重建结合起来。跨场景的共享语义与每个实例的身份需要分别验证。

等逐实例表示稳定后，再接入 SLATE 式自回归解码器或 SlotAdapt 式预训练扩散生成器，检验表示替换、位置改变与未见组合。当前实验没有训练这两种生成主干，也没有训练对象布局分布或从零生成新编码的先验。

本轮只有一个训练随机种子、小样本及单一跨城市测试。没有单棵树评价标注，因而不报告树实例准确率；也不能由当前失败推出无标注方法无法做到这一任务。
