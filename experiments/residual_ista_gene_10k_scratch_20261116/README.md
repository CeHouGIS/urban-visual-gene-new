# 从零训练的残差多尺度加性视觉基因实验

所有实验代码、配置、权重和结果均在本 NAS 目录。独立于此前队列，不加载任何旧实验的编码器、字典或解码器权重。LPIPS 仅作为固定的预训练评价/损失网络，不属于被训练的生成模型。

## 科学问题与两组实验

在共享稀疏加性字典下，多尺度残差监督和卷积原子是否改善真实街景重建？

- `single_scale_ista`：16×16 特征、64 通道、512 个 1×1 向量原子、6 步非负 ISTA。
- `multiscale_residual_ista`：16/32/64 网格，各 64 通道，256/128/128 个原子，核为 1/3/3，分别展开 6 步非负 ISTA。

总基因数均为 512；编码器和 RGB 解码器主干随机初始化一致。中细尺度卷积原子、投影和监督头使参数量及 FLOPs 仍有差异，`runs/*/model_spec.json` 与 GPU smoke 报告记录实际差异。本轮比较整个多尺度设计的效果，不能单凭两组结果独立归因于卷积、残差监督或容量；如有提升再做消融。

所有图像相关的最终解码器输入必须经过字典。各尺度 Z_s = D_s A_s 是严格线性合成；非线性 RGB 解码器不保证单基因 RGB 图像可以相加还原原图。当前系数是空间激活图，不是全局标量或实例分割。

## 稀疏编码

对每个尺度近似求解：

    min_(A>=0) 0.5 ||F - D A||² + lambda ||A||_1

投影特征在每个位置归一化为 RMS=1，各原子单位范数。6 步 ISTA 使用真实字典的伴随算子和 ReLU 近端阈值；步长为可学习 sigmoid 比例乘以保守 Lipschitz 上界的倒数。有限迭代只近似最优解，不声称收敛。lambda 从 0.15 在前 1000 更新内增加到 0.5；无 TopK、使用均匀化或每尺度硬激活配额。记录实际密度和基因集中度，不预设能获得几枚激活基因。

## 残差金字塔监督

RGB 固定金字塔尺寸 64/128/256；降采样用 area，U 用 bilinear/align_corners=False：

    R_c = I_64
    R_m = I_128 - U(I_64)
    R_f = I_256 - U(I_128)

各字典合成的特征接独立、允许正负输出的辅助 RGB 头，监督对应残差。最终街景由带中细尺度注入的非线性主解码器生成。辅助监督鼓励尺度分工，不保证语义独立或完全无冗余。

训练目标：

    L = L1_RGB + 0.1 LPIPS
        + 0.05 mean_s [gate_s (0.5 mean((Z_s-F_s)^2)
                                + lambda mean_spatial(sum_channel(A_s))/64)]
        + 0.05 mean_s [gate_s mean(abs(H_s(Z_s)-R_s)/max(RMS(R_s),0.03))]

残差 RMS 按每图、每尺度由固定目标计算，detach。mean_s 的除数固定为该模型尺度数。

## 从随机初始化逐步启用

- 粗尺度：第 1 更新起启用。
- 中尺度：第 200–600 更新，门控和其辅助损失权重线性从 0 增至 1。
- 细尺度：第 600–1200 更新线性启用。
- 后续联合优化至 6000 更新。

不存在旧模型预训练或继承的粗尺度权重。中细尺度启动前梯度可以为零；GPU smoke 在门控全开时验证全部梯度。初期和最终的总训练目标因 lambda/门控计划不同，跨阶段不能仅按总 loss 判断退化；同时查看 RGB loss 和验证集重建指标。

## 数据、预算和验证

复用现有真实街景清单及机械盘 RGB 缓存，不复制 NAS 原图、不做源图哈希：

- 训练 10,000 张，验证 1,000 张，测试 1,000 张，256×256 RGB。
- 洲→国家→城市均衡采样；训练集 500 个 1km 格网，每格 5 个全景、每全景全部 4 朝向。
- 三个 split 的格网、全景及图片 ID 两两隔离，同城可跨 split。
- 每轮按随机固定格网循环，格网内图片顺序每轮重排；每个全局 batch 的 256 张来自不同格网。
- 每模型两张 GPU，每卡 microbatch 128，不累积，有效 batch 256；两组可共用最多四张空闲卡。
- 每组恰好 6000 次优化更新，即 1,536,000 张次，153.6 遍训练集。
- AdamW，LR 2e-4→2e-5，100 更新 warmup，BF16，梯度裁剪 1。
- 初始验证、第 25 更新验证，之后每 250 更新验证；每 100 更新保存可恢复检查点。
- 按验证集 L1+0.1 LPIPS 选优；测试集仅对选优权重在训练结束后评价一次。

生成模型从头训练；固定 LPIPS 网络使用其公开预训练权重。两组同一 seed 是第一轮可行性实验，结论需要后续多 seed 验证。

## 质量门槛与启动

CPU 只做代码编译、采样与切分检查。GPU 单元测试涵盖字典加性、伴随一致性、ISTA 目标下降、全链路梯度、固定金字塔可还原性、无绕过字典路径等。之后每组进行两卡 DDP 梯度对照、4 张真实图像 20 步学习测试及真实有效 batch 显存检查；smoke 权重全部丢弃。所有门槛通过后自动启动独立主训练。

队列使用项目共享 GPU flock，只占用空闲卡；没有 GPU 则等待，禁止 CPU 训练或推理。共享 RGB 缓存位于 `/workspace/urban-visual-gene/multiscale_gene_10k_20261116/cache`。

状态：`queue_status.json`；各模型：`runs/<variant>/progress.json`。
日志：`logs/`；验证曲线、真实 RGB 重建/误差及残差过程图：`runs/<variant>/`。
最终对照图和指标：`reports/comparison_*`。

停止时仅在本目录创建 `STOP_REQUESTED`；主模型在当前更新后保存恢复状态并停止。恢复仅允许加载本目录的 checkpoint_resume.pt。

## 已通过的启动检查

4 项 CPU 数据检查、9 项 GPU 单元测试、两组双卡 smoke 均已通过。正式训练不继承 smoke 权重。单尺度 5,055,564 参数，多尺度 5,218,782 参数，多尺度多 163,218（约 3.23%）；已记录容量差异。有效 batch 256、每卡 micro128 的 smoke 峰值显存分别为 26.26/29.23 GiB。
