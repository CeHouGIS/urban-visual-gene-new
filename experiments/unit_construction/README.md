# 景观单元构建过程：现有检查点的真实追踪

展示上一轮 `k32-refined` 模型在 London、Austin、Adelaide 各自预先固定的第一张留出图片上的中间结果。没有重新训练模型。

## 单张图像的处理

1. **图块特征**：448×448 图像对应 28×28 个 DINOv3 特征向量。现有试验使用缓存的 1024 维特征，经训练集 PCA 降到 64 维；输入 MLP 映射到 96 维，并加入空间坐标投影。展示的特征颜色仅来自前三个主成分，不是模型识别出的类别。
2. **候选初始化**：32 个 96 维 slot 从学习到的均值/尺度初始化。评估时采用固定噪声；这些候选事先没有被指定为树、房屋等。
3. **竞争分配**：用候选向量生成查询、用图块特征生成键。相似度沿候选维度做 softmax，因此每个图块的权重由所有候选共同竞争。
4. **特征汇聚与向量更新**：对于一个候选，将它的注意力沿图块维度归一化，汇聚图块的 value 特征，再用 GRU 和 MLP 更新候选向量。当前模型重复三次。第 t 轮显示的注意力来自该轮更新前的查询；其旁边的向量图显示该轮更新后的状态。
5. **解码区域权重**：最终候选向量与每个图块位置共同输入共享解码器，预测逐候选特征及区域权重。此处的区域权重和编码器注意力是两个不同的学习输出。
6. **单元候选**：将最终向量与解码区域权重关联，得到候选单元。区域可以覆盖多个不相连部分，也可以同时覆盖不同物体；不能将它自动认定为一个物理实例。

## 跨图像训练为什么会形成分组

各候选解码出的特征按区域权重组合成重建特征图，与输入的 DINOv3 特征计算误差。反向传播同时调整分组网络和共享解码器，使其在多张图像上重复学习如何分配、汇聚与重建。训练不使用实例类别、框或人工 mask。

仅靠当前特征重建目标，没有保证每个 slot 对应一棵树，也没有保证向量维度分别对应颜色、树冠、材质等语义因素。32 是本次指定的候选容量，不是模型推断的树木/对象数量；U01 等编号仅在该图与本次初始化内有效。

新增扩散联合训练方案尚未运行。这份过程追踪来自原有 PCA64 轻量模型，不能当作新架构的实测结果。

## 数据与核对

- `trace.npz`：四个时刻的完整候选向量（初始化、三轮更新）、三轮编码器注意力、最终解码权重及各轮汇聚值，均为原始浮点数。
- `provenance.json`：图片 ID、来源检查点的 SHA256 与核对记录。
- 追踪结果与原模型最终向量、第三轮注意力和解码权重逐元素一致；各图块沿候选维度的权重总和为 1。
- 内联展示为控制大小，向量保留三位小数、软权重以 uint8 近似；最大权重为原始值，硬分组直接来自原始权重的 argmax。
- 浏览器检查通过：七个阶段切换、候选选择与区域点击会更新结果；96维向量正常绘制；360px 视口无横向溢出，未出现 JavaScript 运行错误。

复现数据：从项目根目录运行 `python experiments/unit_construction/export_trace.py`。内联展示保存在当前会话的可视化目录。
