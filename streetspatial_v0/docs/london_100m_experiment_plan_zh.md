# 伦敦 100 米全景先导实验：观察 VLM 内部的三维空间表征

日期：2026-11-12。状态：实验方案和数据盘点已完成；三维重建、模型激活提取和干预实验尚未执行。本文是现有三地点数据的执行方案。

## 1. 要回答的问题

**同一个真实街景地标，在相机转向、沿街移动和跨年份拍摄后，VLM 的内部激活是否按三维几何规律变化？这样的几何信息是否被后续网络计算使用？**

不评分模型的文字回答。研究对象包括视觉编码器和语言模型中对应图像的 token，必须分别报告；只在视觉编码器发现信号，不能直接称为语言模型内部的发现。

需要区分三个结论层次：

1. **可读出**：从隐藏状态中可以预测深度或三维关系。
2. **几何结构**：这种信息跨地点泛化，并服从已知的相机变换规律。
3. **计算中的作用**：只改变候选空间表征，会选择性改变后续层处理几何关系的方式。

这批数据首先检验局部三维场景表征。它不能直接检验模型是否自带全球经纬度地图，也不能证明存在三个固定的“坐标神经元”。

## 3. 先补上几何依据，才能谈三维

当前清单只有 pano ID、经纬度、年月和到锚点距离，缺少可靠的绝对朝向、俯仰、相机高度、三维地标和跨图对应关系。距离锚点 80 米，表示相机到锚点的距离，**不表示画面里某根灯杆离相机 80 米**。

### 3.1 用同一采集月做多视图重建

从全景生成内参已知的重叠透视图，用 COLMAP 或同类 SfM 工具恢复相机和静态点。相同 pano 投影出的多张图共享一个光心，必须作为已知相对旋转的相机组处理；它们不能被当成具有平移基线的独立相机。没有相机组约束的实现，至少要在模型中显式维护共享光心并检查优化结果。

每个地点独立建局部三维场景。经纬度作为带不确定性的相机位置先验，用多台相机联合估计尺度；不能把 GPS 当成厘米级真值。绝对朝向可通过元数据补齐并与重建核对，或者直接使用重建的局部朝向。全景的水平像素零点未经校准，不能直接称为正北。

主模型不参与重建，也不使用其预测深度作为主要真值。若尝试现成深度或重建网络，只作候选或辅助结果，与经典几何和人工核验结果分开报告。

### 3.2 追踪固定点，覆盖不同高度和深度

每地目标为 30–50 个稳定地标点，包括建筑角点、不同楼层窗角、灯杆底部/顶部和固定路牌角点。每个点至少在三张**不同 pano**中可见。车辆、行人、叶片、临时围挡不进入主分析。物体框只作导航，不能以框中心代替固定三维点。

先在一个地点建立约 20 条人工核验轨迹，把流程跑通，再扩展三个地点。新地点的地标标注和质量筛选不得查看模型激活结果。

建议预先登记的重建质量门槛，在 896×672 透视分辨率下为：轨迹重投影误差中位数不超过 2 像素、90 分位不超过 4 像素，最大有效三角化夹角至少 2°。这只是启动门槛，还要报告相机位姿和三维点的不确定性，并做留相机检查。

不能只标路面点。检查三维点分布、不同高度点的数量及几何条件数；如果第三个空间方向不可辨识，就降为地面二维几何或方向/视差实验。尺度不可靠时报告归一化尺度和相对深度，不声称恢复了米制三维坐标。

跨年份默认先分别重建，只用人工确认仍存在的稳定点建立跨日期坐标对齐。拆除、加建或形状变化的物体不作时间稳定性对应。

## 4. 一个地标如何形成三个对照

以已下载画面中的一个固定灯杆顶部为例，先确认它在邻近 pano 中也可见，再建立统一的点 ID。

| 对照 | 实际操作 | 几何上应该发生什么 |
|---|---|---|
| 原地转向 | 同一张全景生成有重叠的不同朝向视图 | 地标到相机的距离不变，相机坐标和图像位置随旋转变化 |
| 沿街移动 | 同月另一台相机观察同一个灯杆顶部 | 相机坐标、深度、视差随相机位移而变化 |
| 历史重拍 | 不同年份观察仍存在的灯杆顶部 | 补偿实际位姿差后，地标在局部世界中的位置应稳定 |

例如，**只为解释而假设**某个点在相机 A 坐标下为 `(4, -3, 20)` 米；相机保持朝向向前移动 10 米后，在相机 B 下应变成 `(4, -3, 10)`。这里坐标依次为右、下、前。模型应体现地标更近了，并保持与其他固定点的几何关系。这些数字不是当前数据的实测坐标。

前向与后向画面可能看见完全不同的地标。对同一地标的变换检验必须选共同可见、无遮挡的视图；不能要求一个已经出画的点仍有对应视觉 token。可用相机穿过地标两侧后的转向视图扩大基线，但须重新确定可见性。

## 5. 送入模型什么，读取什么

冻结本地 Qwen2.5-VL-7B-Instruct，主模型不微调。全景保留作原始数据，每张生成 8 个相对朝向的透视图，间隔 45°、水平视场 90°、分辨率固定为 896×672、俯仰先固定 0°。28 张主全景约产生 224 张输入视图；历史数据另列。

这些朝向最初是相对全景零点的角度，经位姿校准后才能转到共同参考系。投影、缩放、模型处理器、patch 合并和位置编码的参数全部记录。一个全景的所有视图保持相同数据划分。

图像后接固定的中性文本，不给坐标、地名、地标名称或画框，不调用生成接口。保存：

- 视觉编码器浅层、中层、末层和 token merger 输出。
- LLM 中图像 token 对应的各层残差状态，先稀疏采样层，再用训练集内部验证选层。
- 地标点映射到的 token 及邻域，记录精确像素/token 对齐。稠密激活图用于查看空间分布。

LLM 是因果网络，放在图像后面的文本不会反向改变更早的图像 token。这也意味着这种读取主要检验 LLM 对视觉输入的处理，不等价于读取“回答问题时的思考”。

## 6. 四项主实验

### E1：是否包含超出屏幕位置的深度信息

在训练地点的激活上拟合简单的线性读出，分别预测相机坐标、距离/深度和地标间深度顺序。读出器仅是测量工具，不能通过大网络自己完成三维重建。

主比较包括：像素/token 网格位置；只有方向、没有深度的相机射线；类别与二维位置；局部外观特征；视觉编码器对应层；相同容量的随机投影。未知的真实深度不能塞进基线。用训练数据拟合“二维位置和语义可解释部分”，再检查隐藏状态是否能解释留出数据中的剩余深度；残差化步骤也必须交叉拟合。

报告深度排序、相对深度误差、三维误差及其尺度条件。绘制视觉编码器到 LLM 各层的曲线，检验 LLM 层是否保留、改善或损失了几何可读性。如果只在视觉编码器有效，结论停留在视觉编码器。

### E2：内部坐标是否服从真实的旋转和平移

对同一点的两个观测 A、B，使用外部重建得到的相机位置 `C_A/C_B` 和相机到世界的旋转 `R_A/R_B`，检查冻结读出的结果是否满足：

```text
p_B ≈ R_Bᵀ (R_A p_A + C_A - C_B)
```

分别报告纯旋转与真实平移误差。只比较每幅图中的独立 XYZ 预测分数不足以完成这个实验。预测点再通过已知相机位姿转到共同世界系，检查同一地标的多次预测是否聚在一起，以及不同地标之间的距离和夹角是否保留。

世界坐标转换由分析程序完成，不表示模型自己知道经纬度或正北。测试时不按每幅图重新做旋转、尺度或平移拟合，否则可能把误差对齐掉。

纯旋转检验本身较弱：仅有屏幕位置和相机射线也能满足不少旋转关系。因此 E2 的关键增量是有非零平移基线的结果，且必须胜过这些基线。

### E3：几何表征能否跨年份保持

对稳定地标，先用独立几何估计补偿相机位置和朝向差，再比较隐藏状态中的几何投影。同一地点内跨日期测试单列，不能算作未见地点泛化。

同时观察完整激活的变化与候选几何部分的变化：外观发生变化时，几何部分是否比外观部分更稳定。报告残余位姿误差和真实场景变化；单纯“两个年份激活相似”可能只是认出了同一物体，不足以说明有坐标系。

### E4：干预候选空间子空间，观察后续内部计算

仅在 E1/E2 有信号后开展。候选子空间、层和干预强度都用训练地点确定。令 `Q` 为同一激活坐标尺度下的正交基，使用真实观测的供体激活，进行温和的部分替换：

```text
h' = h + α Q Qᵀ (h_donor - h),  α ∈ {0, 0.25, 0.5, 1}
```

优先用同一地标在其他自然视图中的供体，并匹配类别/纹理、屏幕位置和激活范数；无法匹配时明确保留混淆。另设空替换、等秩等范数随机子空间、二维位置/语义方向、反向替换和恢复原状态对照。干预前后检查激活分布偏离程度。

后层读出器必须独立拟合、冻结，并报告未干预 token 的变化。只观察被修改 token 的 XYZ 读出变了，属于有限的传播证据；不能独自证明模型使用了坐标表征。

更强的扩展是双视图输入：让较早图像 A 的 token 可被后面的图像 B 关注，只干预 A 的候选分量，观测 B 中未直接干预的对应地标、内部对应匹配与注意力分布是否选择性变化。加入单图、重复图、无关地点图、A/B 顺序交换控制。注意力图只是辅助证据。只有几何效应、语义保留、随机对照与独立读出共同支持时，才谨慎讨论几何信息参与了后续计算。

全程不使用文字回答分数。自然供体替换仍会改变内部状态而非真实场景，阴性结果或选择性不够时必须保留，不用“读出变了”替代因果验证。

## 7. 如何探索“类似三维的维度”

先显示训练地点确定的候选几何轴在测试图像中的激活热图，以及各层几何信号。候选轴通常是许多神经元的组合；坐标轴可以旋转、缩放，不必恰好对应三个单独维度。

一个关键限制：**线性解码器只有 XYZ 三个输出时，矩阵的秩最多就是 3。把秩设为 4 或 8 不会增加线性模型容量，因此不能用这种“秩扫描饱和”证明内部只有三维。**

实际做两类补充：

- 比较秩 1/2/3 的读出，检验预测三个独立坐标是否需要三个线性方向。这只是读出能力检验。
- 在训练数据上拟合不同维数的无监督子空间，例如 2/3/4/8/16/32，冻结后评估深度、跨视角变换和跨时间稳定性；结合几何相关变化的谱、随机子空间和局部非线性诊断，探索几何信息需要多少表示维度。普通 PCA 的三维效果差也不代表没有空间编码。

三维图用于展示候选读出，不作为维数证明。线性探针失败，也不能排除非线性或分布式几何表示。

## 8. 数据隔离、统计和判定

三个地点做三轮留一地点测试，每轮在另两个地点内完成选层、正则化和任何特征选择，再冻结到第三个地点测试。内部验证按地点分组，必要时在两个训练地点间交换训练/验证后重拟合。跨年份稳定性采用独立的日期留出方案，分开报告。干预子空间和后层读出可在两个训练地点之间交叉拟合，不能用测试地点挑方向。

同一地点的原图、旋转图、历史图及相同地标，不得随机拆到主泛化实验的训练和测试。不得把数百个旋转视图当成数百个独立街景样本。

这是 **3 个独立地点的先导实验**。逐地点报告效应、相机/地标数和测量不确定性；地点内的重采样区间不能当成跨城市置信区间。若流程和几何信号成立，再按预定规则扩展至至少约 30 个独立地点，才做更有把握的地点级统计。

| 实测情况 | 可以支持的结论 |
|---|---|
| 只预测出屏幕左右上下 | 二维位置信息可读出 |
| 隐藏状态比位置、射线、语义基线更能预测未见地点深度 | 深度信息存在于这些层的表示中 |
| 再通过真实平移、旋转及历史稳定性检验 | 存在与三维几何一致的表征证据 |
| 再有选择性干预和未直接修改 token 的独立效应 | 增强几何表征参与内部计算的证据 |
| 只有三个输出或三维散点图 | 不构成内部三维维数的证据 |
| 位姿/点云质量不过关 | 暂停三维结论，保留方向/视差分析 |

## 9. 执行顺序与交付

1. 一个地点先做 5–8 张不同 pano、约 20 个地标的重建核验；检查共享光心、尺度和第三空间方向。通过后扩展三个地点的 28 张主全景。
2. 生成约 224 张透视视图、固定点轨迹、相机位姿和三维质量报告；形成按地点隔离的清单。
3. 提取冻结模型内部状态，先完成 E1/E2；输出各层深度增量和变换误差，保留失败结果。
4. 核验历史稳定点，完成 E3；随后在有几何信号的层开展 E4。
5. 交付三类主要图：地标在多视图中的对应图；内部候选几何读出与外部点云对照；各层指标、轴激活和干预对照图。真实结果和解释示意图分别标记。

立即应做的下一步是第一项几何核验。当前已经具备多位置、历史全景，但尚未具备可以直接宣称“三维坐标真值”的标注。
