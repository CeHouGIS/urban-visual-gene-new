# StreetSpatial V0.2：VLM 内部是否形成三维地理坐标表示？

状态：实验设计，尚未执行；没有新增实测结果。日期：2026-11-12。

基于已下载的伦敦 3 地点、551 张全景，当前执行方案见 [伦敦 100 米先导实验](london_100m_experiment_plan_zh.md)。该方案补充了位姿与三维标注门槛、真实采集月份、三地点泛化限制，以及内部干预的判定边界。

## 1. 研究对象

核心观测量是模型内部视觉 Token 在各层的隐藏状态，不评价模型最终回答。具体问题是：同一个固定街景点在不同相机位置、朝向和采集时间下，对应的隐藏状态能否被一个跨场景复用的低维几何子空间表示；这个子空间是否有三个稳定方向，可对应局部坐标 `X/Y/Z`；干预这些方向后，后续层的内部几何状态是否按预期变化。

这里的“三维维度”不预设为三个单独神经元。真实网络更可能用多个神经元组成分布式子空间。实验要检验的是“需要约三个独立自由度才能解释可泛化的三维几何”，而不是先强制投影成三维、再把三维输出误当作发现。

## 2. 数据：同地点跨时间与沿街多视点

### A. 同一全景原地转向：旋转控制

对同一张 360° 全景渲染多个 heading，固定透视 FOV、分辨率和处理器设置。相机中心、采集时间和场景均不变，只改变观察方向。它提供已知的纯旋转变换，可校准模型内部坐标是否随相机旋转而变换；它本身不能恢复深度。

### B. 同一地点跨时间重复采集：外观稳定性对照

把用户已有的同地点不同时期图像按采集点、相机位置和朝向配对。人工追踪跨日期仍存在的建筑角点、立杆、路牌等固定点；车辆、行人、施工区域和季节变化明显的树叶不作核心对应点。

如果朝向和相机中心基本相同，固定点的三维坐标应保持不变，图像颜色、天气、光照变化则作为外观扰动。这样的配对检验内部几何表示是否对时间外观变化稳定。如果朝向有变化且元数据可校准，它还能作为自然旋转泛化测试。只有很小的视角差时，不把它当作足够强的几何变换；变化量必须大于相机位姿及人工标注误差。

### C. 沿街前后视点：三维深度主数据

为检验真正的 `Z` 方向，需有同一路段沿街向前/向后的多个相机中心，建议先导至少 30 个街段、每段 3 个以上视点，并尽量有跨时间重复拍摄。单个地点的重复照片或 360° 原地转向没有平移基线，不能单独提供可靠深度真值。

用全景元数据和多视图特征匹配恢复局部相机位姿与静态场景点；可从全景生成已知内参的透视视图进行多视图重建。以人工核验的静态地标作为质量检查，用相邻全景位置基线给重建尺度。剔除重投影误差过大、只在单视图出现、跨日期已经改变的点。若重建位姿/尺度质量达不到预设标准，只报告二维方向及相对视差，不报告三维坐标发现。

现有 200 张全球随机全景适合 A 类旋转和部分 B 类同点跨时间分析；由于彼此不是相邻街道视点，它们不能替代 C 类平移数据。

## 3. 隐藏状态怎么取

冻结 Qwen2.5-VL-7B-Instruct，不微调主模型。对每个固定分辨率视图，保存视觉编码器浅层/中层/末层、视觉 Token merger 输出，以及 LLM 若干层中对应图像 Token 的隐藏状态。保留图像 Token 到原图像素和全景射线的精确映射。

三维地标通过多视图重建匹配回相应图像 Token。用人工确认的局部特征点或小区域提取状态，并按实际 token 覆盖区域加权；框只用于辅助匹配和检查，不以框中心作为三维标签。每个 token/局部特征点都保存相机位姿、局部三维真值、图像坐标、可见性和跨时间稳定性。

主分析直接读取视觉 Token 激活，不在提示中告诉模型目标名称、框或坐标，也不读取答案位置的隐藏状态。这样观测的是视觉表征，而不是模型组织语言答案时形成的空间描述。

## 4. 实验一：隐藏状态中是否有可泛化的三维几何子空间

令 `h_{i,l}` 表示第 `l` 层中与三维点 `i` 对应的视觉 Token 状态。先按街段/地点把训练、验证、测试彻底隔离；同地点不同日期、不同朝向和同一三维点的所有视图必须进入同一划分，避免同一场景泄漏。

使用训练集拟合受 rank 限制的线性映射：

```text
h  →  u ∈ R^k  →  (X, Y, Z)
```

对三个输出的线性映射，仅比较有效秩 `k=1,2,3`；其矩阵的秩最多为 3，`k=4/8` 不会增加容量，不能用这种饱和来证明内部维数。另在训练数据上拟合 2/3/4/8/16/32 维无监督子空间，固定后比较留出几何指标，作为维数探索。三维读出有效不等于发现三维内在结构。

主标签使用局部相机系。通过外部相机位姿把各视图的预测点转到局部世界系后，检查同一静态点是否一致；此转换由分析程序完成，不预设单图模型知道任意世界坐标原点或正北。重点看未见街段的深度增量及真实平移下的几何一致性。

评估包括三维点误差、深度顺序、点间距离/角度关系、跨视角同点一致性和刚体变换一致性。所有指标在留出的整段街道上报告，并按街段做 bootstrap 置信区间。

必须比较以下基线：

- 仅用 patch 网格位置或图像 `(u,v)` 的二维位置基线。
- 仅用类别/外观特征的语义基线。
- 类别加二维位置基线。
- 打乱三维标签、打乱跨视图对应关系的负基线。
- 相机射线但不含深度的基线。

其中图像坐标能解释 `X/Y` 的部分变化；若 `Z` 仅凭图像平面坐标无法跨视点恢复，且隐藏表示在未见场景有稳定深度/尺度信息，才构成超越分割和框定位的证据。分数可解码仍不是因果证据。

## 5. 实验二：直接观察三个候选轴

若 rank-3 子空间通过留出场景测试，固定其变换矩阵，并将每个对应视觉 Token 投影到候选 `X/Y/Z` 激活坐标。生成三类图：

1. **隐藏空间点云**：每个静态街景点按 `X/Y/Z` 投影成 3D 点云，与重建真值点云做刚体对齐，显示同一地点跨相机和跨日期是否重合。
2. **轴激活图**：把 token 的 `X/Y/Z` 投影值和梯度/特征消融贡献映射回对应视图，观察每一轴是否跟踪几何方向或深度，而非只响应某个类别、颜色或屏幕位置。
3. **子空间结构图**：显示三轴方向、秩 `k=1/2/3/4/8` 的泛化误差与跨视角一致性，确认三维结构是否由数据支持。

线性子空间、留出重建、激活归因和消融属于本实验的主要可解释方法。稀疏自编码器可以作为后续探索，查看坐标信号是否由少数可解释特征承载；不把 SAE 特征数目当成坐标维数，也不要求 `X/Y/Z` 各自对应单个神经元。

## 6. 实验三：内部激活替换，不读模型回答

在 rank-3 候选子空间 `U` 和层 `l` 固定后，选一对语义相近、几何位置不同的静态点。取源点激活 `h_A` 和自然视图中的供体点激活 `h_B`，只把源激活在候选几何子空间的分量替换为供体分量：

```text
h'_A = h_A - U Uᵀ h_A + U Uᵀ h_B
```

继续运行网络后续层，但不生成或评分语言答案。用另一组地点训练、冻结的后层 XYZ 解码器读取受影响 token 和邻近 token 的新几何表示。检验源点的后层三维表征是否沿供体方向移动、对应距离/深度关系是否变化，同时语义特征及非目标点是否保留。

因果对照包括：同一地点同一激活的空替换、等范数随机三维子空间、只替换单一轴、反向替换、恢复原激活、语义方向替换、未干预 token 和不同层。几何解码器与干预子空间必须在地点划分上独立训练；如果被替换的同一探针同时用于宣称干预成功，会形成循环论证。

支持性证据应同时满足：rank-3 几何在留出街段泛化；激活图的轴方向可解释；几何子空间替换选择性改变后续层的三维内部状态；随机/语义子空间对照没有相同效果。即使如此，结论也限定为“这些层的视觉激活中存在并使用了三维几何子空间”，不声称模型只有一套坐标系或三个单独神经元。

## 7. 结果如何解释

| 观察 | 结论范围 |
|---|---|
| 只从视觉 Token 读出 `X/Y/Z`，但 `k=1/2` 也同样好，或仅在训练街景有效 | 坐标信息可读出；没有三维潜在子空间证据 |
| `k=3` 在未见地点恢复三维关系，跨视角按位姿变换、跨时间对稳定 | 支持可泛化的三维几何子空间 |
| 轴激活图与三维几何对应，且与类别/像素位置基线有区别 | 增强可解释性，但尚未证明因果使用 |
| 几何子空间互换可选择性地移动后层内部 XYZ 状态，随机与语义控制无同等效果 | 支持模型内部使用该三维子空间组织视觉几何 |
| 只有图像平面 `X/Y` 稳定、`Z` 不稳定 | 支持二维位置编码，不能声称发现三维坐标系 |
| 干预无效 | 当前层、Token、线性子空间或数据精度下没有因果支持；不能据此证明模型没有几何表征 |

报告只呈现激活、几何投影、点云、归因图、消融和内部状态变化。模型的自由回答准确率、语言输出得分不作为实验结果。

## 8. 执行顺序

1. 先盘点同地点跨时间采集的 pano ID、经纬度、日期和 heading；选 30 个街段/地点检查稳定地标与视角差。
2. 用同一全景转向做纯旋转控制；同时用跨时间同点对做外观稳定性检验。
3. 补齐有真实平移基线的沿街相邻全景，建立局部多视图三维点和相机位姿；先通过重建质量门槛。
4. 提取冻结模型各层视觉 Token，完成 rank-受限三维读出、跨视角/时间检验、轴归因图和后层激活干预。
5. 交付逐街段数据划分、位姿和点云质量报告、各层激活缓存、秩扫描曲线、三维可视化、激活干预对照及阴性结果。
