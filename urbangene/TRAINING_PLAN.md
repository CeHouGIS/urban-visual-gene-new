# UrbanGene V0 训练安排

安排日期：2026-11-08（北京时间）。当前规格：[需求原文](REQUIREMENTS.md)。

## 本轮研究范围

先在可控 2D 合成城市图像上检验跨场景共享、重复实例与未见组合的表征泛化。
模型是 `冻结 AE 编码 → 离散程序 → 共享模板 → Place/Transform/Overlay → 冻结 AE 解码`。
Gene 阶段唯一训练目标是 latent L1；没有自由连续残差、逐图模板或原图跳连。
本轮没有无条件生成模型、DINO/SAE 分解或真实街景训练。

## 训练顺序

| 顺序 | 工作 | 默认配置 | 完成后的检查 |
|---|---|---|---|
| 0 | CPU smoke 与测试 | 32 训练图，AE/Gene 各 3 epochs；四种模型 | 有限 loss、有效梯度、离散程序可独立还原、无旁路 |
| 1 | 准备合成数据 | train 20,000；其余四个 split 各 2,000；256 RGB | 因素/组合/seed 审计与预览 |
| 2 | 单独训练图像 AE | 8×32×32 latent，卷积 width24，30 epochs | 完整 val_seen 的 PSNR/SSIM 和重建图；固定最佳 AE |
| 3 | 主模型 | K64，M16，8×8 Gene；30 epochs | 正确程序与跨图打乱程序的内容对应、使用率、失败图 |
| 4 | 结构基线 | B0 / B1 / B2，各 30 epochs | 共享 AE、相同图像曝光、近似参数规模、实际程序比特数 |
| 5 | 容量矩阵 | K={32,64,128} × M={8,16,32} | 9 组（含主模型），得到容量—重建关系 |
| 6 | 坐标精度 | grid8 / grid32；grid16 已在主模型中 | 固定 K64/M16，对比 240/304 bits 与主模型 272 bits |
| 7 | 锁定与独立测试 | 按 val_seen latent L1 选择各固定配置检查点 | test_seen / test_unseen_combo / test_higher_complexity 全部评估 |

共 **14 组 Gene 训练**：9 个容量配置 + 3 个结构基线 + 2 个位置精度配置；另有 1 次 AE 和 1 次独立评价器训练。
先用 seed42；多训练种子确认不在这轮自动队列中，不能据单种子宣布稳定优势。

## 预先声明的继续条件

- AE 验证 PSNR 至少 24 dB，才继续正式 Gene 阶段。这是本项目选定的工程就绪线，不是领域公认标准；仍须检查细结构和属性是否可恢复。
- 主模型在同一验证集上的 latent L1，需比跨图打乱程序至少低 1%，才继续其余 13 组实验。这仅用于排除完全不依赖输入的退化解，不代表科学问题已经解决。
- 任一条件失败，队列保存 `diagnosis_required` 后停止；不会自动堆新 loss、修改阈值或开始真实街景实验。
- 数值异常、程序编码不一致或源代码在运行中变化会停止并记录；测试结果不用于调整配置。

## 数据与组合划分

三种建筑形态 × 三种立面 × 三种植被布局，共 27 个三因素组合。
保留 6 个三因素组合仅用于未见组合测试；21 个用于训练、验证和已见测试。
每个单因素值和每种二因素组合均在训练规则中出现。
道路宽度、建筑左右高低关系、颜色、尺寸、地平线和位置扰动同时变化。

训练树木数量为 1–3，复杂度测试为 4–5；加上两个建筑和道路，显式场景构件数为 7–8，未超过最小 M8。
这不是 Gene slot 与真实物体一一对应的假设：窗口和纹理也可能消耗多个 Gene。

所有图像按 scene_spec/独立 seed 即时确定性渲染，仅保存 manifest 和少量预览。
只缓存训练/验证的 AE latent，约 344 MiB（fp16）；测试 latent 不预先缓存。
审计保证 seed 和完整参数化无交集；同类因素模板有意共享。未做全量渲染图像哈希去重，不能将参数化隔离描述为像素去重证明。

## 信息预算与基线公平性

主模型每 slot 固定支付 `Gene ID 6 + enabled 1 + position 8 + scale 2 = 17 bits`。
16 slots = **272 bits = 34 bytes/scene**，关闭 slot 也付费；真实二进制文件经过 round-trip 验证。
这只是场景程序，不包括共享模型，不是实测通用图像压缩率。

| 模型（K64/M16） | 程序 bits | 可训练参数 | 说明 |
|---|---:|---:|---|
| UrbanGene | 272 | 1,650,672 | 重复 Gene + 位置 + 尺度 + 固定加权 Overlay |
| B0 | 252（字节存储256） | 1,649,780 | 6×7 规则网格离散 patch 编码；无实例位置/尺度选择 |
| B1 | 112 | 1,651,906 | 共享小模板全局 resize 后求和；无位置和尺度 |
| B2 | 272 | 1,650,672 | 相同组合器，但每张图的 Gene ID 不得重复 |

编码器通过调整有效隐藏层宽度匹配参数量，不添加无用参数。B0 比主模型少 7.4% 程序位数；B1 的信息预算明显更低，只能作为结构消融，不能单独证明组合机制在相同信息预算下更优。
共享 Gene 库另有 32,768 个参数（fp32 128 KiB）；解析器与冻结 AE 的参数量也单独报告。

## 评价口径

- 重建：latent L1、RGB L1、PSNR、7×7 均匀窗口 SSIM；逐图数据及按重复数量的分组结果。
- 组合：seen / held-out / higher-complexity 分开报告。目标图输入后的重建，不称为无目标生成。
- 属性：独立轻量评价器，在专用合成校准语料上训练，包含全部因素值、组合和数量，seed 与 Gene 数据隔离。其标签从不进入 Gene/AE 训练。
- 评价器先评原始测试图。某个属性原图准确率低于85%，该属性重建分数标记不可靠，不能作为主要结论。
- 诊断：启用实例数、Gene 使用率、跨图打乱、实例覆盖图、原图/AE/Gene 对照、按误差排序的失败案例。
- 输出质量—比特曲线时同时报告共享权重成本、单种子限制、未匹配的预算项；不以 smoke 图支持任何科学主张。

## 资源与队列

采用单 GPU 串行队列。启动前要求同一 GPU 连续三次满足利用率≤10%、空闲显存≥12 GiB，间隔45秒；磁盘至少余2 GiB。
这是可见资源检查，不是集群独占预约。队列不终止其他任务，也不同时启动多组 GPU 训练。
AE 可用 bf16；Gene 渲染和 straight-through 梯度采用 float32。batch32；Adam lr3e-4；不使用额外正则项。
每组 20,000/32×30 = **18,750 次 optimizer updates**，14 组共 262,500 次；实际耗时以日志为准，不提前承诺完成时间。
保留 last/best 两个检查点、每 epoch 指标和配置快照，支持恢复。
