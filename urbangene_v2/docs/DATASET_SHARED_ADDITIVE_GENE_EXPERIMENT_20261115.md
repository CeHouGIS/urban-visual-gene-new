# UrbanGene：数据集共享的可加视觉基因分解

日期：2026-11-15（北京时间）  
状态：修订后的研究方案，未实现新模型、未启动训练。  
本方案根据用户最新表述，取代“整张街景编码相加的融合”作为当前研究主线；旧方案保留用于追溯。

## 1. 研究目标

从一组真实街景中共同学习 n 个可复用的视觉变量，使每张图通过这些变量的不同取值，在特征空间中相加后重建出来。

当前科学问题：

> 能否在没有类别、实例和语义标签的情况下，联合学习图像编码器、共享视觉字典和解码器，使街景可以由少量字典成分的加和高质量重建，并且这些成分能够跨图像复用、接受有规律的干预？

工作定义：这里的“相加”发生在特征空间，之后通过非线性图像解码器还原 RGB。它不要求 RGB 像素本身满足线性叠加。如果以后要求每个变量直接对应一层可相加的 RGB 图，需要另立更强的模型约束与实验。

不再以两张完整图的编码相加生成第三张图作为首要任务，因此首阶段不需要融合目标 C 或生成式教师三元组。

## 2. 共同的字典与每张图自己的配方

给定数据集 X={I_1,...,I_M}，共同学习：

- n 个共享字典向量 d_1,...,d_n：暂称为视觉基因，所有图像使用同一套字典。
- 每张图的系数 a_i=(a_i1,...,a_in)：控制每个基因在该图中的使用强度。
- 图像编码器 E：从新图像推断系数，不把训练图像 ID 作为输入。
- 图像解码器 D：从基因贡献的加和还原图像。

概念模型：

\[
a_i=E_\theta(I_i),\qquad
z_i=\sum_{k=1}^{n}a_{ik}d_k,\qquad
\hat I_i=D_\phi(z_i).
\]

定义图像 i 中基因 k 的贡献为 g_ik=a_ik d_k，则有：

\[
\boxed{\hat I_i=D_\phi\!\left(\sum_{k=1}^{n}g_{ik}\right)}.
\]

同一套固定向量无权重地相加只会得到同一个结果；能够还原不同图片的是每张图不同的系数。严格区分字典成分 d_k、变量取值 a_ik，以及该图的贡献 g_ik。

n 是全数据集可用的字典成分数量；它不是图片数，也不等于每张图的对象数。首版 n 是需要比较的容量超参数，不声称自动找到了唯一正确的变量数量。

## 3. 街景需要保留空间位置

仅用一个全局标量表示某个基因的强度，很难高效表示它在不同位置的重复出现。首版建议将系数扩展为空间激活图：

\[
A_i=E_\theta(I_i),\qquad
Z_i(:,u,v)=\sum_{k=1}^{n}A_i(k,u,v)d_k,
\qquad
\hat I_i=D_\phi(Z_i).
\]

其中 d_k 属于 R^c，A_i 为 n×h×w，Z_i 为 c×h×w。完整公式是：

\[
\boxed{
\hat I_i=D_\phi\!\left(
\sum_{k=1}^{n}d_k\otimes A_i(k,:,:)
\right)
}.
\]

外积在这里表示：用同一个 c 维向量乘以每个位置的激活强度，得到 c×h×w 的贡献张量；所有贡献张量逐元素相加。

这仍然是共享的 n 个基因，只是每张图给每个基因分配一张强度与位置图。相同基因可在多个位置激活，但激活图不自动等于物体实例 Mask，也不保证一棵树对应一个基因。n 个字典方向同样不自动具备统计独立性或语义解耦性。

## 4. 为什么只写一个求和公式还不够

任意向量都能按坐标基展开，普通 AE 的特征也能写成求和。因此，求和这一结构本身不能证明模型发现了有意义的分解。

首版加入以下可检验的限制：

1. 全数据集共享有限字典，避免为每张图片单独学习自由基因。
2. 每个空间位置只激活少量字典成分，限制共同编码的复杂度。
3. 不允许输入图像、多尺度跳连、未分解残差、图片 ID 等绕过字典瓶颈。
4. 评价未见图片，检查模型是否只是记住训练集。
5. 在相当重建质量下报告实际活跃系数、索引和幅值所需的信息预算。

这些限制有助于获得紧凑、可复用的编码，但不能仅凭无监督重建保证唯一分解或人类可命名的因素。空间先验和稀疏性也可能优先产生纹理、边缘和颜色成分，需要由实验观察决定。

## 5. 推荐首版：直接面向 RGB 的空间稀疏字典 AE

流程：

```text
真实街景 I
    ↓
可训练图像编码器 E
    ↓
n 通道候选激活 → 非负化 → 每个位置保留至多 s 个激活
    ↓
用共享字典把各激活转为基因贡献张量
    ↓
所有贡献逐元素相加，得到 Z
    ↓
可训练非线性图像解码器 D
    ↓
RGB 重建 I_hat
```

可用 ReLU 和 Top-s 实现非负稀疏激活。每个 d_k 约束单位范数，以约定字典与系数的尺度。固定稀疏预算优先于首版仅靠 L1 惩罚：E/D 联合训练时，仅依赖幅值惩罚可能通过缩小编码、放大解码器来绕开约束。

固定 Top-s 也不保证有效编码量固定：还要记录系数幅值分布，使用统一量化精度估算索引与数值成本，并检查实际非零数。Top-s 的支撑预算是约束，不把“恰好只有 s 个非零值”当作自动发现稀疏因素的结果。

初始实验配置建议而非已执行配置：

- 输入 256×256 真实街景，编码器为卷积或层级视觉网络。
- 特征网格先设 16×16、通道数 c=64；以普通 AE 的重建表现为依据调整。
- 字典大小先比较 n=128、256；每个位置激活预算 s=2、4、8。
- 编码器、字典和图像解码器最终都接受 RGB 重建梯度；已有权重只作为初始化选项。
- 不以冻结 DINO 特征重建作为主训练目标，不把 Slot Attention 作为必要模块。

## 6. 损失与优化

首版主要优化：

\[
\mathcal L_{\rm rgb}
=\|\hat I-I\|_1
+\lambda_p\operatorname{LPIPS}(\hat I,I),
\]

同时满足共享字典、单位字典范数和每位置至多 s 个激活的结构约束。lambda_p 可从 0.1 起步，通过固定验证集选择。

稀疏结构本身限制了分解，不必一开始叠加大量额外损失。监测死字典项、激活集中度、重复字典方向以及解码器对编码的敏感性。首版不强迫每个基因等频使用，也不把字典向量正交作为必需条件；过完备字典不可能所有方向两两正交。

如有明确退化，再分别比较软稀疏、局部性或已知图像变换的一致性约束，避免一次加入多个因素后无法判断原因。提高自然度的对抗或生成式解码器放在重建基线成立之后单独比较。

## 7. 实验顺序

### S1：建立普通 RGB AE 基线

使用现有真实街景中固定的 20,000 张起步，并准备来源独立的验证和测试集。优先核查全景、地点和近重复来源的划分；可复用的原验证集须满足这一条件。先确认普通编码器/解码器在该分辨率能清晰重建。

交付：原图与重建、PSNR/SSIM/LPIPS、损失曲线、编码容量。

### S2：加入共享稀疏字典瓶颈

用同一组 RGB 数据联合训练 E、字典和 D。普通 AE 可以用于结构或权重初始化，但最终主模型必须经过端到端图像训练。无需 (A,B,C) 三元组。

交付：相同图片的普通 AE 与字典 AE 重建、重建质量—编码预算曲线、n/s 消融、每个基因的跨图像激活样例。

### S3：检查分解是否可复用

对固定基因 k，在多张未见图片中展示它的激活位置、强度和去除该贡献后的输出变化。使用统一色标和固定挑选规则，不能只展示最好看的个例。

检查字典是否在多张图上被使用，以及同一基因的视觉作用是否随上下文完全漂移。使用频率不等于稳定的视觉功能；重建质量高也不等于解耦成功。

### S4：检验干预与未见组合

固定其余贡献，只对一个基因做置零、减弱、增强，再尝试跨图像替换选定的激活图。所有实验应注明哪些干预偏离训练分布，以及空间位置是否匹配。

记录局部/全局变化、输入保真、自然度和两个变量共同干预的交互。非线性解码器允许存在交互，不把特征相加解释为像素独立。

不应让被删除部分的编码仍以原整图为重建目标，否则可能鼓励解码器忽略删除并补回全部内容。首版删除实验用于诊断；若要训练可控编辑，需另外定义合法目标或一致性依据。

### S5：按瓶颈扩大规模

先判断问题来自 AE 细节不足、字典容量不足、稀疏过强还是变量作用不稳定，再扩大到更大数据集或更高分辨率。只有重建与干预证据成立后，再研究跨街景合成与新组合生成。

## 8. 必需对照与评价

| 对照 | 检验目的 |
|---|---|
| 普通 AE | 字典约束造成多少重建代价 |
| 相同字典、不施加稀疏限制 | 稀疏性是否改善紧凑性与复用 |
| 固定随机字典、可训练 E/D | 可学习字典是否优于换一种坐标表示 |
| 预训练后冻结编码器再做字典分解 | 联合重训图像表示的收益 |
| PCA 或固定特征的稀疏字典基线 | 区分经典分解与端到端 RGB 方法的效果 |

尽量控制解码器、数据曝光和训练预算。普通 AE 与字典 AE 同时报告性能—信息预算曲线，不能仅比较名义通道数；稀疏系数还需要存储激活位置和字典索引，字典本身也有模型存储成本。

主要评价：

- 重建：PSNR、SSIM、LPIPS，以及固定未见照片的可视化。
- 编码：实际非零数、估算比特率、基因使用率、死项和重复度。
- 复用：同一基因跨图片的激活与干预表现，不以使用次数单独下结论。
- 稳定性：不同训练种子字典对齐后的相似性，并报告不稳定因素；字典排列可变不是失败。
- 泛化：未见来源、城市和景观条件下的重建与变量作用。
- 组合：有明确目标的受控任务上检验新组合；真实图的自由编辑先作为探索性结果。

字典全局统计来自训练集，验证和测试不能用于更新字典。最终主要对照应多种子重复，并按来源图像/全景分组统计。

## 9. 能够与不能够从实验中推出什么

若在可比较预算下实现高质量重建，且少量共享成分在未见图片上可复用，可支持“学到了共享稀疏的可加街景表示”。

若干预产生稳定、可重复的视觉效果，可进一步支持“这些成分具有可操作的视觉功能”。

前两者不能自动推出每个成分是对象实例、变量彼此独立、分解唯一、任意新组合自然，或找到了城市景观的真实因果因素。这些均需要独立证据。

建议论文表述：

> 本研究从无语义标注的街景图像集合中，端到端学习共享视觉字典、空间稀疏激活与图像解码器。每张图像由少量共享基因在不同位置的加权贡献叠加后重建。我们通过重建—编码预算、跨图像复用、变量干预及未见场景测试，研究这种可加分解能否形成紧凑且具有稳定视觉作用的街景表示。
