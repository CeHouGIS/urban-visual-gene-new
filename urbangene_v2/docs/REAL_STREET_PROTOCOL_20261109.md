# 真实街景首轮实验（2026-11-09）

用户指出此前展示的是合成街景。V2 的主线从本轮起切换到真实照片。
两轮合成图结果保留为诊断记录，不能当成真实街景结论。

## 本轮数据

- 使用 NAS `/host/mnt/nas/huangyj/GoogleSV/images/` 的真实 Google 街景原始文件。
- 沿用 `experiments/object_centric_pilot/data/dinov3/manifest.json` 的全景级划分：
  Austin、Bogota、Lagos、London 各 128 张训练图、16 张验证图，总计 512 / 64。
- 每个全景只取一张视角。逐张核对源文件 SHA256、图像可读性和训练/验证隔离。
- 原始跨城市测试图不打开、不提取特征、不用于选择检查点；该旧测试集曾用于历史
  pilot，因此今后正式确认研究结论还应使用新保留的测试集。
- 不使用历史缓存、PCA 或标签。用已校验的本地 DINOv3 权重重新提取全部照片。
- 图像清单只有 `id,image,split`。完整来源单独保存在 `provenance.json`。

## 本轮模型与预算

真实照片 → 冻结 DINOv3 ViT-L/16 → 28×28×1024 特征 → 32 个候选 Slot → 特征重建。
32 是容量上限，并不代表照片中有 32 个对象。

采用已有空间初始化版模型，从头训练、不加载合成实验检查点。先保持架构不变，
建立真实数据的可复现诊断基线。随机种子 42；CPU；batch 4；10 epochs / 1280 updates；
AdamW，学习率 0.0003。检查点只按固定随机数的验证特征重建误差选择。

本轮不修改主模型架构，不能检验模型修改是否有效，也不能证明该架构最优。
GPU 均有任务，因此本轮使用 CPU；后续 GPU 任务最多两张卡。
所有新产物位于新的 NAS 子目录，原队列、检查点和结果不覆盖。

## 先检查什么

1. 原图：固定展示每个城市验证清单的前两张，展示真实输入。
2. DINOv3 特征：PCA 仅在训练特征上拟合，验证图仅投影显示；颜色不是语义标签。
3. 编码器区域：展示注意力分配；颜色表示候选 Slot，不表示已识别的树或房子。
4. 解码器区域：同时展示最强分配和软权重强度，避免把接近均匀的权重画成成功分割。
5. 记录重建误差、训练集均值基线、区域占用和权重熵，判断模型是否塌缩。

真实数据没有独立实例标注，因此本轮不报告 FG-ARI、实例 IoU、单棵树召回，
不宣称 M1 实例发现通过。区域稳定、特征重建降低也不能单独证明逐棵树发现成功。
当前阶段不生成新街景；PCA 颜色图不是生成图片。
