# 连续 Slot 组合诊断与后续训练

## 本次实现

`src/urbangene_v2/composition.py` 提供独立的 `SlotProgram`：连续槽位向量、中心和尺度、存在值、启用状态、来源记录。支持删除、平移、尺度变换、跨图替换、固定容量内复制及保存/加载。

这是一种 M1 连续表示编辑诊断，不是 PRD 的共享离散 Gene 程序，不声称满足最终程序的编码预算。诊断没有更新任何模型参数。

解码仅接收被编辑后的 SlotProgram 与共享解码器，重新计算融合权重；不读取 A/B 的原始特征图或原预测 mask 作为解码输入。A/B 图像特征仅用于最初编码，A 的原重建用于变化评估。没有目标 C。

复制不会自动扩容。本次按固定规则移除一个权重最小的其他前景槽位，再将所选单元复制到腾出的位置。指标单独保存“仅腾出槽位”的控制，以免把删除带来的变化全归因于复制。

## 观察与边界

| 诊断 | Austin/London | Lagos/Bogota |
|---|---:|---:|
| 请求横向移动（归一化坐标） | +0.50 | +0.50 |
| 实际权重中心横向移动 | +0.4207 | +0.4400 |
| 跨图替换的特征变化 MSE | 0.003679 | 0.001288 |
| 替换变化能量位于诊断支持区的比例 | 99.55% | 99.42% |

支持区是编辑前后槽位 argmax 区域的并集，再向外膨胀一格 patch；来自模型自身，不是独立真值。高比例仅说明变化在此定义下局部集中，不是物体编辑准确率。只有两对图、单种子，未评价内容身份保持、遮挡合理性或真实图像质量，未通过正式组合泛化 gate。

当前解码器输入包含绝对坐标和相对坐标，连续 Slot 也可能携带原位置与上下文。调整 geometry 并不数学保证内容平移等变；实测位移与请求存在偏差。这需要后续归纳偏置和训练验证，不能仅靠把张量拼接起来认定实现了物体组合。

## 组合阶段需要训练什么

1. **先保留当前发现模块，训练共享离散 Gene 表达。** 冻结 DINO 和已验收的发现模块，把连续槽位编码为少数共享 Gene ID，训练 Gene 编码器、字典和共享组合器，使它们重建槽位/局部视觉信息。量化、字典利用率和码率单独报告。
2. **训练共享局部内容解码与场景融合。** 先验证图像 AE 对真实街景的重建上限，再冻结它。以 Gene ID 组合码和量化几何为唯一场景输入，预测局部 AE latent 模板及透明度，按布局放置后融合，重建整图 AE latent。优先使用局部相对坐标；所有单元共享参数。背景也通过受限编码提供。
3. **先用单图重建检验能否学出可复用生成部件。** 主损失为真实图像 AE latent 与组合结果之间的 L1。这能训练单元生成及融合，但不保证未见组合合理；不额外预设一组复杂正则。
4. **独立评价组合。** 冻结模型，编辑 A/B 的程序，检查移动、复制、删除和替换。生成 C 时不输入 C 的任何派生结果；没有目标 C 的真实街景编辑只能做适当无配对评价或人工评价，不能伪造配对重建误差。
5. **必要时另设组合监督实验。** 若无组合监督主模型失败，可在另立协议下使用配对 A/B/C 训练共享解码/融合器。C 可作训练损失目标，但不能作为生成器输入；必须与没有组合监督的主实验分开报告，评价使用未参与训练的组合。

SAE 和 GRCT 不属于本次编辑接口的依赖；只有简单共享解码器经诊断仍有具体关系建模问题，再独立比较 GRCT 的贡献。
